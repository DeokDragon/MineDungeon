# 최신 레퍼런스 맵 구현·검증 기록

기준일: 2026-10-21. 첨부 이미지 두 장의 **구조**를 반영한 플레이 가능한 블록아웃이다. 이미지 픽셀, 불명확한 치수 문자, 과거 테스트 방 크기를 월드 치수로 환산하지 않았다. 최종 암벽·바닥 아트 제작은 포함하지 않았다.

## 시작 상태와 보존

- 사용자가 Discard 실행을 확인했다. 최초 Git 검사에서 추적 파일 변경은 없었고 `WORK_STATUS.md`, `기획/`만 미추적이었다. 추가 Discard/reset/파일 삭제는 하지 않았다.
- Main 씬: 변경 전 콘솔 오류 0, Missing Script 0, 깨진 프리팹 0. Mine Entrance Korean 폰트의 일부 한글 글리프 누락 경고는 작업 전부터 있었다.
- 기존 일반 방 두 종류는 각각 적 6마리, 일반 방 수 3개 후 보스 방이다. 기존 프리팹·GUID·몬스터 참조와 난이도 구현 여부를 유지했다.
- 문서의 StoneMonsterAI, IronMonsterAI, CrystalMonsterAI, CoalMonsterAI, MagnetMonsterAI는 모두 실제로 존재한다. NormalMonsterAI/IMonsterAI, DungeonRoom/RoomController/RoomExit/DungeonRoomManager, 저장·보상·런 시스템도 존재하므로 재생성하지 않았다.
- Cinemachine 패키지 없이 직교 Camera + CameraFollow를 사용한다. 기존 사망 집계·보상·저장·인벤토리·보스 공격 코드와 방 진행 코드는 수정하지 않았다.

## 치수 근거

실제 플레이어 충돌체 0.8×0.8, 일반 몬스터 상자 충돌체 1×1, 철 몬스터 원 지름 1.2. 플레이어 이동 속도 4, 회피 거리 2/실제 설정 시간 0.15초, 기본 공격 범위 1.5. 카메라는 orthographicSize 4.5, 16:9에서 표시 범위 16×9이다. 수정 몬스터 사거리는 프리팹 설정 6.5이며 코드 기본값과 다르다.

- 새 후보 공통 외곽: **32×44**, 좌하단 (-16,-22), 우상단 (16,22).
- 바닥의 최대 범위: x=-14..14, y=-20..20. 외곽 암벽 여백은 최소 2이며 비어 있는 내부 공간도 암벽으로 채운다.
- 경로 격자 간격 0.5, 공통 경로 여유 폭 최소 1.3을 검사한다. 선분과 확장된 암벽 사각형 전체의 교차를 검사해 모서리 통과를 방지한다. 실제 이동에는 기존 Rigidbody2D 충돌/캐스트를 유지한다.
- 맵 6 통로 6은 철 몬스터 지름 1.2보다 충분히 넓고, 회피 거리 2와 기본 공격 지름 3을 수용한다. 포켓 연결 공간 높이 10, 대기 공간 폭 12를 둔다. 다른 맵은 아래 표의 지역별 폭을 사용한다.
- 극단적인 화면 비율·확대 설정에서 화면이 맵보다 커지면 카메라 표시 크기를 직사각형에 맞게 제한한다. 추적·흔들림을 적용한 최종 카메라 위치도 다시 제한한다.

모든 새 방의 적 총수는 **6**이다. 기존 고정 배치 구조를 유지하며 런타임 무작위 적 생성은 추가하지 않았다. 주황색 표시는 배치 영역으로 해석했다. 선로와 크레인 장식에는 충돌체가 없다. 상자·광차 충돌, 무너진 벽 파괴·숨겨진 방·외부 탈출 기능은 추가하지 않았다. 최신 이미지가 없는 맵 5·8·9는 재설계하지 않았다.

전체 직사각형은 기존 DungeonRoom의 localMin/localMax, 실제 바닥·암벽·몬스터 영역은 RoomWalkableLayout의 별도 배열, 입구/부활과 출구는 기존 참조로 관리한다. 프리팹 계층도 WalkableFloor/BlockingRock/PassableRails/MonsterAreas로 구분한다. 내부 암벽은 카메라 제한에 사용하지 않는다.

## 실제 수행한 검증

Unity 6000.3.12f1 **Play Mode에서 프로그램으로 조작한 통합 검사**이며 수동 키보드 플레이를 했다는 의미는 아니다. 실제 Rigidbody2D 물리 스텝, 기존 AI/스킬 코루틴, EnemyHealth.TakeDamage, 출구 Trigger, PlayerHealth 사망·부활 코루틴을 실행했다. 사용자 저장 파일 대신 기존 SessionState 테스트 경로 훅으로 Library 아래 별도 저장 파일을 사용했고 종료 후 훅을 해제했다.

| 실행 | 결과 |
|---|---|
| 대표 맵 6 최종 재검증 | 137개 검사 통과 |
| 맵 4 | 116개 검사 통과 |
| 신규 A | 117개 검사 통과, 중앙 암벽 반대편 플레이어 추적 포함 |
| 맵 1 | 116개 검사 통과 |
| 맵 2 | 123개 검사 통과, 두 출구 후보 각각 선택·미선택 차단 검사 포함 |
| 맵 3 | 117개 검사 통과 |
| 맵 7 | 118개 검사 통과 |

공통 검사는 실제 바닥 이동으로 모든 배치 영역과 출구 앞에 도달, 일반 이동·회피의 벽 차단, 실제 프리팹의 공격 사거리까지 다섯 종류 몬스터 추적, 전멸 후 기존 출구 개방과 다음 방 이동, HP·물약·부활 횟수 유지, 현재 방 입구 부활, 세 번째 사망의 런 실패를 포함한다. 카메라는 4:3/16:9/21:9/4:1, 직교 크기 3/4.5/12, 네 모서리·입구·출구, 부드러운 추적·흔들림 중 화면 네 귀퉁이가 전체 직사각형 안에 있는지 검사했다.

대표 맵 6의 추가 검증:

- 기존 TryCast로 플레이어 드릴을 실행해 벽에서 정지 확인.
- 철 몬스터 실제 공격 코루틴을 실행해 직선 유지 및 벽에서 종료 확인.
- 돌 몬스터에 벽 너머 착지 요청을 주어 기존 Jump의 몸체 캐스트가 이동을 거부하는지 확인.
- 수정 투사체 실제 코루틴이 최대 사거리 전에 암벽에서 종료되는지 확인.
- 사망 전에 플레이어 스킬·수정 투사체를 발생시켜 사망 시 효과 정리 확인.
- 맵 6→맵 4의 실제 출구 전환, 이전 공격 효과 정리, 변경된 현재 입구 (-9,-17)에서 부활 확인.
- 적마다 사망 피해를 두 번 요청하고 금화·경험치·재료 중복 증가 없음, 사망 집계 6, 방 이동 후 런 기록 유지 확인.
- 벽에 붙은 목표 위치와 철 돌진 종료 후의 여유 공간 복귀 방향도 추가 조회하여 유효한 경로 확인.

모든 후보는 별도 인스턴스를 만들어 **실제 Collider2D.Distance**로 적 6마리 각각의 벽 겹침과 적끼리 겹침이 없음을 추가 확인했다. 관련 Missing Script와 누락 참조는 0이다.

검증 후 실제 Floor1 쉬움 데이터에 추가하고 원래 설정인 일반 방 3개 + 보스 1개로 전체 런을 실행했다. 시드 606에서 맵 7→6→7→기존 돌골렘 보스로 진행했고, 적 18+보스 1 사망 집계, 클리어, 결과 정산을 확인했다. 보스 처치 검사는 피해 API로 완료했으며 보스의 모든 공격 패턴을 재검증한 것은 아니다.

원문 로그는 이 문서 옆 `맵검증결과/`에 보관한다. 재현 도구는 `Assets/Editor/MineMapPlayProbe.cs`이며 Play Mode 시작 전 `MineDungeon.SaveTestPath` SessionState 값을 격리 경로로 지정하고 `MineMapPlayProbe.Begin("06")`처럼 호출한다. 생성 도구 `MineMapBuilder.Build(id)`는 기존 후보가 있으면 덮어쓰기를 거부한다.

- `Assets/Prefabs/Rooms/ReferenceMaps/Map_{06,04,A,01,02,03,07}.prefab` 및 Unity가 생성한 .meta: 새 후보 7개.

## 남은 사항과 제한

- 최종 확인 시 콘솔 오류 0, Main 씬 Missing Script/깨진 프리팹 0, 관련 방·몬스터 프리팹 Missing Script 0. 기존 한글 폰트 경고는 이 작업 범위에서 수정하지 않았다.
- 암벽/바닥/크레인은 구조 확인용 블록아웃이다. 최종 아트, 다양한 장비·스킬 조합의 장시간 수동 전투, 다수 적이 동시에 밀집할 때의 장시간 플레이·성능, 실제 여러 장치에서의 화면 변경은 별도 확인 범위다.
- 중앙 크레인 이동 불가 해석과 이번 월드 크기는 구현·검증한 설계안이며 최종 밸런스 확정 수치로 간주하지 않는다.
- 맵 5·8·9의 최신 형태는 미확정이며 기존 맵을 추측해 대체하지 않았다.
