## 1. 시스템 개요

### 1.1 목적

보상 시스템은 플레이어가 던전에서 획득하는 돈, 경험치, 재료, 아이템 및 스킬 보상의 획득 조건과 지급 시점을 관리한다.

던전 클리어와 실패 이후에도 기존에 획득한 보상이 올바르게 유지되도록 하며, 보상 중복 지급이나 손실을 방지하는 것을 목표로 한다.

### 1.2 주요 기능

- 몬스터 처치 보상 지급
- 경험치와 돈 즉시 획득
- 일반 몬스터 재료 확률 드롭
- 획득 보상 인벤토리 연동
- 아이템 획득 HUD 알림
- 던전 클리어 전용 보상
- 던전 실패 시 기존 획득 보상 유지
- 런 단위 보상 기록
- 던전 결과창 보상 표시
- 보상 지급 중복 방지
- 저장 및 불러오기 시스템 연동

### 1.3 보상 분류

보상은 획득 조건에 따라 구분한다.

| 분류 | 획득 조건 | 지급 시점 |
|---|---|---|
| 몬스터 처치 돈 | 해당 몬스터 처치 | 처치 즉시 |
| 몬스터 처치 경험치 | 해당 몬스터 처치 | 처치 즉시 |
| 일반 몬스터 재료 | 처치 후 드롭 판정 성공 | 처치 시 직접 획득 |
| 엘리트 처치 보상 | 해당 보상이 존재하는 경우 | 기존 지급 규칙 확인 필요 |
| 보스 관련 보상 | 보스 처치 및 관련 보상 조건 | 현재 보상 데이터 확인 필요 |
| 클리어 전용 아이템 | 던전 클리어 | 최초 결과 진입 시 지급·저장 |
| 스킬 | 던전 클리어 보상 | 클리어 보상 처리와 연동 |

보스 보상과 클리어 전용 아이템의 실제 데이터 구분, 중복 여부 및 지급 구성은 프로젝트 확인이 필요하다.

## 2. 몬스터 처치 보상

### 2.1 공통 규칙

몬스터를 처치하면 해당 몬스터에 설정된 돈과 경험치를 즉시 획득한다.

몬스터별 돈과 경험치 지급량은 서로 다르게 설정할 수 있는 구조이다.

돈·재료 등 기존 보상 규칙은 유지한다. 경험치는 아래 확정 정책과 §2.5의 1층 쉬움 초기 테스트안을 구분하며 실제 지급량 적용·검증은 별도 작업이다.

### 2.2 돈 지급

- 몬스터 처치 시 해당 몬스터의 돈을 지급한다.
- 획득한 돈은 플레이어 보유 돈에 반영한다.
- 해당 런에서 획득한 돈을 기록한다.
- 던전 결과창에서 이미 지급한 돈을 다시 지급하지 않는다.

획득한 돈은 던전 실패 여부와 관계없이 유지한다.

### 2.3 경험치 지급

- 몬스터 처치 시 경험치를 즉시 지급한다.
- 지급한 경험치는 성장 시스템에 반영한다.
- 경험치 누적으로 레벨업할 수 있다.
- 이전 승인된 Lv.1 초기3P·레벨업당3P·최대Lv.50/총150P 성장 규칙을 유지한다. 신규 경험치안의 실제 성장 구현 완료를 뜻하지 않는다.
- 해당 런에서 획득한 경험치를 기록한다.

경험치와 레벨업 처리의 상세 규칙은 `ProgressionSystem.md`를 따른다.

**2026-10-22 확정 정책:** 같은 층·난이도·몬스터 종류는 맵이 달라도 항상 같은 EXP를 지급한다. 맵별 총 EXP는 실제 몬스터 종류·수량의 합으로 달라진다. 경험치는 처치 시 즉시 지급하며 **방·던전 클리어 EXP 보너스는 없다**. 실패 시 이미 획득한 EXP를 유지한다. 기존 랜덤 맵 선택·독립 몬스터 배치는 변경하지 않는다.

### 2.4 직접 획득

현재 일반 몬스터 보상은 아이템을 바닥에 생성한 뒤 플레이어가 줍는 방식이 아니라, 처치 결과에 따라 직접 획득하는 방향이다.

재료 획득 시 인벤토리와 획득 알림 UI에 반영한다.

아이템을 획득하기 위해 추가 상호작용을 요구하지 않는다.

### 2.5 1층 쉬움 EXP 초기 테스트안 — 시험 기준 승인

| 몬스터 | 1마리당 EXP 초기안 |
|---|---:|
| 돌 | 4 |
| 철 | 5 |
| 수정 | 5 |
| 석탄 | 4 |
| 자철석 | 6 |
| 돌골렘 | 45 |

2026-10-27 사용자 승인으로 위 초기안을1층 쉬움 시험 기준으로 사용한다. 최종 밸런스가 아니다. WORK_STATUS의25일 초기 밸런스 기록은 실제값이 이미4/5/5/4/6·보스45여서 유지했고 격리 기능런EXP173을 확인했다고 보고한다. 이번에 현재 에셋/Unity 지급을 독립 재확인하지 않았으며 새 적용/Play 완료를 선언하지 않는다. 과거 기록의 일반 EXP10·보스 EXP50은 이전 구현 이력으로 보존하며 이 초기안과 혼동하지 않는다. 기존 공유 보상 에셋·돈·재료 지급량을 수정하거나 초기안의 구현 방식을 확정하지 않는다. 보통/어려움/악몽 및 2층 이후 EXP는 미확정이다.

### 2.6 과거7맵 배치 기준 예상 EXP — 역사적 계산값

**과거 자료:** 아래Map_01~07과187/216/약199.71EXP는 이전7종/당시 배치 기준이다. 현재RegularCaves10종에 적용하지 않는다. 신규 승인10종 배치 목표의 산술 예상은 §2.7을 따르며 과거7종 계산을 덮어쓰지 않는다. 처치 즉시EXP·실패 유지·클리어EXP 보너스 없음과 중복 지급 방지는 유지한다.

## 3. 일반 몬스터 재료 드롭

### 3.1 적용 대상

현재 제공된 명세에 포함된 일반 몬스터는 다음 5종이다.

1. 돌 몬스터
2. 철 몬스터
3. 수정 몬스터
4. 석탄 몬스터
5. 자철석 몬스터

각 몬스터는 자신의 계열에 해당하는 제작 재료를 드롭한다.

정확한 재료 아이템 이름과 데이터 ID는 Unity 프로젝트를 확인한다.

### 3.2 드롭 확률

**최신 확정 규칙**

일반 몬스터 처치 시 재료 드롭 성공 확률은 50%이다.

드롭에 성공하면 재료를 1~2개 획득한다.

제공된 인수인계 문서에 기록된 수량 균등 추첨 기준의 분포는 다음과 같다.

| 드롭 결과 | 확률 |
|---|---:|
| 획득 없음 | 50% |
| 재료 1개 | 25% |
| 재료 2개 | 25% |
| 합계 | 100% |

### 3.3 판정 흐름

1. 몬스터 사망이 확정된다.
2. 해당 몬스터의 재료 드롭 판정을 진행한다.
3. 50% 확률로 드롭 성공 여부를 결정한다.
4. 드롭에 성공하면 1개 또는 2개를 결정한다.
5. 해당 재료를 플레이어의 인벤토리에 반영한다.
6. 획득 알림을 표시한다.
7. 런 획득 기록에 반영한다.

### 3.4 적용 범위

50% 드롭 확률과 1~2개 지급은 일반 몬스터에 대한 공통 규칙이다.

보스 및 엘리트 몬스터에 동일한 확률을 임의로 적용하지 않는다.

해당 적의 보상은 별도의 기존 데이터 또는 확정 기획을 따른다.

### 3.5 구현 검증 사항

- 모든 일반 몬스터가 자신의 재료를 지급하는지
- 드롭에 실패한 경우 재료가 지급되지 않는지
- 드롭에 성공한 경우 수량이 1~2개인지
- 사망 이벤트 중복 처리로 보상이 중복 지급되지 않는지
- 인벤토리와 런 기록에 획득 결과가 일치하게 반영되는지

## 4. 던전 클리어 보상

### 4.1 클리어 조건

던전의 보스를 처치하면 던전 클리어 조건을 만족한다.

던전 클리어 보상은 몬스터 처치 보상과 별도로 구분한다.

### 4.2 클리어 보상 지급

**확정된 핵심 규칙**

던전 클리어 결과창을 최초로 표시하는 과정에서 클리어 보상을 지급하고 저장한다.

보상 지급은 결과창의 열기·닫기 동작에 종속되지 않아야 한다.

클리어 보상 지급 흐름:

1. 보스 처치
2. 던전 클리어 상태 확정
3. 최초 결과 진입 과정에서 클리어 보상 지급
4. 획득 보상 저장
5. 결과창 연출 및 획득 정보 표시

보상 지급 이후 결과창을 닫거나 다시 열어도 지급 상태를 유지한다.

### 4.3 클리어 전용 아이템

던전 클리어 보상에는 클리어 전용 아이템이 포함될 수 있다.

스킬은 던전 클리어 보상으로 획득하는 기존 확정 구조를 따른다.

**확인 필요**

- 층별 클리어 보상 목록
- 난이도별 보상 목록
- 개별 아이템의 획득 확률
- 개별 보상 수량
- 보스 보상과 클리어 전용 보상의 구분
- 스킬 보상 목록 및 획득 확률

인수인계 자료에 없는 아이템이나 확률을 임의로 추가하지 않는다.

### 4.4 돈·경험치 클리어 보너스

**최신 확정 규칙**

별도의 던전 클리어 돈 보너스는 없다.

별도의 던전 클리어 경험치 보너스도 없다.

클리어 결과창에 표시되는 돈과 경험치는 해당 런에서 몬스터 처치 등을 통해 이미 획득한 수치를 기준으로 한다.

결과창 표시를 이유로 동일한 돈이나 경험치를 다시 지급하지 않는다.

### 4.5 기존 보상 상자 방식 폐기

이전 기획에서는 보스 처치 후 던전 중앙에 보상 상자를 생성하고 T 키로 상호작용하는 방식을 사용했다.

현재 이 방식은 폐기되었다.

최신 기획에서는 별도 상자 상호작용 없이 클리어 보상을 지급하고 결과창으로 연결한다.

## 5. 던전 실패 보상

### 5.1 실패 조건

플레이어가 부활 가능 횟수 2회를 모두 소모한 뒤 세 번째 사망을 하면 던전 실패가 확정된다.

### 5.2 기존 획득 보상 유지

**최신 확정 규칙**

던전 실패 시에도 이미 획득한 보상은 100% 유지한다.

유지 대상:

- 돈
- 경험치
- 재료
- 이미 획득한 아이템

실패했다는 이유로 해당 런에서 획득한 보상을 차감하지 않는다.

### 5.3 미획득 보상

아직 획득하지 않은 클리어 전용 보상은 지급하지 않는다.

보스 처치 조건을 만족하지 못했다면 미획득 보스 보상 역시 지급하지 않는다.

### 5.4 엘리트 몬스터 보상

향후 또는 현재 프로젝트에 엘리트 몬스터가 존재하고 처치 보상이 지급된 경우, 이미 지급한 보상을 실패 시 회수하지 않는다.

엘리트 보상의 세부 내용은 현재 기획에서 확정하지 않는다.

### 5.5 실패 결과창

실패 결과창에는 실패 전까지 획득한 보상을 표시한다.

결과창에서 보상을 다시 지급하거나 회수하지 않는다.

## 6. 런 보상 기록

### 6.1 목적

런 보상 기록은 한 번의 던전 플레이에서 획득한 보상을 결과창에 표시하기 위한 정보이다.

영구 보유 재화 및 인벤토리 데이터와 구분한다.

### 6.2 기록 대상

| 항목 | 기록 내용 |
|---|---|
| 돈 | 해당 런에서 획득한 돈 |
| 경험치 | 해당 런에서 획득한 경험치 |
| 재료 | 획득한 재료 종류와 수량 |
| 아이템 | 획득한 아이템 종류와 수량 |
| 보스 보상 | 해당 런에서 실제 획득한 보상 |
| 클리어 보상 | 클리어 시 실제 지급한 보상 |

### 6.3 방 이동

방을 이동해도 해당 런에서 획득한 보상 기록은 유지한다.

새로운 방으로 이동한다는 이유로 이전 방의 획득 기록을 삭제하지 않는다.

### 6.4 클리어와 실패

클리어 시에는 일반 전투에서 획득한 보상과 실제 지급된 보스·클리어 보상을 기록한다.

실패 시에는 실패 전에 실제 획득한 보상만 기록한다.

### 6.5 런 종료와 재시작

결과창을 닫거나 다시 열어도 동일한 런의 기록을 보여준다.

같은 던전과 난이도로 다시 시작하면 새로운 런의 보상 기록을 사용한다.

기존 영구 보유 재화와 아이템은 유지한다.

런 기록의 실제 초기화 시점 및 데이터 구조는 기존 구현과 함께 확인한다.

## 7. 보상 지급 중복 방지

### 7.1 기본 원칙

하나의 보상 획득 사건으로 인해 동일한 보상을 의도치 않게 여러 번 지급하지 않아야 한다.

### 7.2 몬스터 처치 보상

한 몬스터의 사망이 중복으로 처리되어 돈, 경험치, 재료가 여러 번 지급되는 문제를 방지한다.

기존 몬스터 사망 이벤트 및 보상 처리 구조를 확인한다.

### 7.3 클리어 보상

동일한 런의 클리어 보상은 최초 결과 처리 시 지급한다.

다음 동작으로 보상이 반복 지급되어서는 안 된다.

- 결과창 닫기
- 결과창 다시 열기
- 결과창 표시 연출 반복
- 로비 복귀
- 저장 처리 재호출

### 7.4 보상 지급과 결과 표시 분리

결과창은 이미 확정된 보상 데이터를 표시하는 기능을 수행한다.

단순히 결과창을 열고 닫는 UI 동작을 보상 지급 조건으로 재사용하지 않는다.

### 7.5 저장 연동

보상이 지급되었으면 해당 획득 결과를 저장 시스템에 반영한다.

결과창에서 로비로 이동하는 버튼을 눌러야만 보상이 저장되는 구조에 의존하지 않는다.

정확한 중복 지급 방지 구현 방식과 저장 순서는 `SaveSystem.md` 작성 및 실제 코드 확인 과정에서 검토한다.

## 8. 획득 알림 HUD

### 8.1 기본 방향

플레이어가 아이템 및 재료를 획득하면 화면에 알림을 표시한다.

### 8.2 표시 위치

기존 기획 기준:

- 화면 우측 중앙 부근
- 세로 방향으로 나열
- 최신 획득 알림은 위쪽
- 기존 알림은 아래로 이동

### 8.3 표시 정보

각 획득 알림의 기본 구성:

- 아이템 아이콘
- 아이템 이름
- 획득 수량

몬스터 재료 획득도 알림 대상이다.

### 8.4 표시 동작

아이템을 획득하면 해당 정보가 화면에 표시된다.

기존 알림이 존재할 경우 새 알림은 위쪽에 배치하고 이전 알림은 아래로 이동하는 방향이다.

알림 유지 시간, 최대 표시 수량 및 페이드 연출 등은 현재 구현을 확인한다.

### 8.5 획득 알림과 실제 지급

획득 알림은 보상 지급 사실을 표시하는 UI이다.

UI 알림이 닫히거나 사라지는 것과 무관하게 실제 지급된 보상은 유지한다.

## 9. 던전 입장창 보상 미리보기

### 9.1 목적

플레이어가 던전 입장 전에 획득 가능한 클리어 보상을 확인할 수 있도록 한다.

### 9.2 표시 대상

던전 입장창에는 클리어 보상 목록을 표시하는 방향이다.

일반 및 엘리트 몬스터의 개별 처치 보상은 향후 별도 도감 화면에서 확인하는 구상이 존재한다.

도감 기능은 구현 완료로 확인되지 않았다.

### 9.3 보상 표시 정보

- 아이템 아이콘 또는 이미지
- 획득 확률
- 희귀도에 따른 테두리

보상 목록은 좌측에서 우측으로 나열한다.

획득 확률의 최종 정렬 기준은 실제 구현 확인이 필요하다.

### 9.4 난이도 연동

던전 선택창에서 난이도를 변경하면 해당 난이도의 보상 정보를 갱신한다.

실제 보상 데이터와 미리보기 내용이 서로 일치해야 한다.

단, 난이도별 정확한 보상 및 확률은 현재 프로젝트 데이터를 확인한다.

## 10. 던전 결과창 보상 표시

### 10.1 기본 역할

결과창은 한 런에서 실제로 획득한 보상과 전투 기록을 표시한다.

보상을 중복 지급하는 기능이 아니다.

### 10.2 획득 아이템 영역

기존 확정된 결과창 구성:

- 4열 아이템 그리드
- 8종 초과 시 세로 스크롤
- 획득 아이템 종류 수 표시
- 아이템 아이콘
- 희귀도 테두리
- 획득 수량 배지
- 마우스 호버 툴팁

### 10.3 희귀도 색상

| 희귀도 | 표시 색상 |
|---|---|
| 일반 | 회색 |
| 고급 | 초록 |
| 희귀 | 파랑 |
| 영웅 | 보라 |
| 전설 | 금색 |

아이템의 실제 희귀도는 기존 아이템 데이터를 따른다.

### 10.4 돈 표시

해당 런에서 획득한 돈을 표시한다.

표시 예시: `+ N G`

돈은 황금색 계열로 표현한다.

### 10.5 경험치 표시

해당 런에서 획득한 경험치를 표시한다.

표시 예시: `+ N EXP`

관련 UI에는 현재 레벨, 경험치 퍼센트 및 경험치 바가 포함된다.

경험치는 이미 지급된 값을 표시하며 결과창에서 재지급하지 않는다.

### 10.6 카운트업 연출

기존 결과창에는 골드와 경험치의 카운트업 연출이 포함되어 있다.

카운트업은 표시용 애니메이션이다.

숫자가 증가하는 연출에 맞춰 실제 재화를 반복 지급하지 않는다.

### 10.7 결과창 재열기

결과창을 닫은 뒤 다시 열면 동일한 런에서 확정된 보상 데이터를 표시한다.

재열기 시 추가 보상 추첨이나 재지급을 진행하지 않는다.

상세 레이아웃과 애니메이션은 `UISystem.md`에서 관리한다.

## 11. 보상과 제작 시스템 연동

### 11.1 경제 순환 구조

현재 확정된 기본 경제 구조는 다음과 같다.

몬스터 처치

→ 돈과 재료 획득

→ 메인 씬에서 곡괭이 제작

→ 곡괭이 장착

→ 던전 재도전

### 11.2 제작 재료

일반 몬스터로부터 획득한 재료는 곡괭이 제작에 활용하는 구조이다.

개별 곡괭이의 재료 요구량과 제작 비용은 아직 확정되지 않았다.

### 11.3 제작 시 보유 재화

곡괭이 제작 기능은 플레이어가 보유한 돈과 재료를 참조한다.

제작 시 재화 소모와 곡괭이 지급의 세부 규칙은 `EquipmentSkillSystem.md`에서 관리한다.

### 11.4 추가 경제 기능

다음 기능은 본 문서에서 새로 확정하지 않는다.

- 아이템 판매
- 아이템 분해
- 곡괭이 강화
- 랜덤 옵션 부여
- 재료 교환

추가 기획 및 사용자 승인 없이 보상·경제 구조에 적용하지 않는다.

---

## 12. 저장 시스템 연동

### 12.1 영구 유지 대상

획득 보상 중 영구적으로 보유해야 하는 데이터는 다음과 같다.

- 돈
- 경험치 및 레벨
- 재료
- 획득 아이템
- 보유 스킬
- 제작한 곡괭이 및 장비

### 12.2 보상 저장 시점

클리어 보상은 최초 결과 진입 과정에서 지급 및 저장한다.

이미 획득한 처치 보상은 결과창에서 다시 지급하지 않는다.

### 12.3 로비 복귀

결과창 또는 퍼즈 메뉴를 통해 로비로 이동하더라도 이미 지급한 보상은 유지해야 한다.

다만 클리어·실패가 확정되기 전의 자발적 던전 이탈에 대한 상세 규칙은 현재 자료에서 확정되지 않았다.

### 12.4 게임 종료와 재실행

획득하고 저장한 보상은 게임을 종료하고 다시 실행해도 유지되어야 한다.

정확한 자동 저장 시점과 저장 실패 대응 방식은 기존 구현을 확인한다.

### 12.5 저장 데이터 초기화

개발용 저장 초기화 기능이 요청된 이력이 있다.

해당 기능은 보상 시스템의 일반적인 소비 기능과 구분한다.

실제 구현 여부 및 초기화 범위는 `SaveSystem.md`에서 확인한다.

## 13. 다른 시스템과의 관계

| 관련 시스템 | 연동 내용 |
|---|---|
| DungeonSystem | 런 시작·종료, 클리어·실패 조건 |
| MonsterSystem | 사망 이벤트, 돈·경험치·재료 지급 |
| BossSystem | 보스 처치 및 보스 관련 보상 |
| ProgressionSystem | 경험치 지급과 레벨업 |
| EquipmentSkillSystem | 재료 소비, 곡괭이 제작, 스킬 획득 |
| UISystem | 획득 알림, 입장창 보상 미리보기, 결과창 |
| SaveSystem | 지급 보상 저장 및 복원 |
| PlayerSystem | 플레이어 보유 재화와 런 상태 |
| MapSystem | 방 진행 중 획득 기록 유지 |

### 13.1 주요 충돌 위험

**몬스터 시스템**

몬스터 사망 이벤트가 여러 번 처리되면 보상이 중복 지급될 수 있다.

**던전 시스템**

방을 이동하거나 런을 종료할 때 획득 보상 기록이 의도치 않게 초기화될 수 있다.

**UI 시스템**

결과창을 열고 닫는 과정이 보상 지급 로직을 다시 실행할 수 있다.

**저장 시스템**

보상 지급 결과가 저장되지 않은 상태에서 로비로 이동하거나 게임이 종료되면 보상이 손실될 수 있다.

**제작 시스템**

제작에 사용되는 돈·재료의 보유량과 실제 저장 데이터가 일치해야 한다.

| 자철석 | Magnetite | 50%, 성공 시 1~2개 |

- 당시 일반 몬스터 돈 10 / EXP 10은 구현 데이터이며 최종 난이도별 금액을 확정하지 않는다. Stone의 기존 ID/GUID와 저장 수량은 유지한 기록이다.
- 클리어 전용 스킬·아이템은 결과 최초 진입 과정에서 자동 추첨·정산하고 즉시 저장한다. lastSettledPlayId와 보유 데이터를 같은 스냅샷에 넣고 결과 재열기·저장 재시도 때 재추첨/재지급하지 않는다.
- 실제 연결 기록은 1층 쉬움만이다. **임시 테스트 표:** EarthSmash(대지 분쇄) 10%, Stone 100% 1~3개, 항목별 독립 추첨. 이미 보유한 스킬은 추가 지급/획득 표시하지 않는 구현이다. 다른 층·난이도의 미리보기나 20/30/40% 표시는 실제 지급 연결의 증거가 아니다.
- 별도 클리어 돈·EXP 보너스, 일반 몬스터의 직접 스킬 드롭, 보스 상자 T 개봉은 사용하지 않는다.
- 획득 알림은 우측 중앙, 최신 상단, 3초 유지 + 0.3초 페이드, 최대 5줄과 FIFO 대기열이다. 같은 처치 내 재료 ID를 합산하고 방 이동에서 유지, 결과/새 도전에서 표시를 정리한다. 정리해도 실제 보상은 유지한다.

**기록된 Unity MCP 테스트:** 2026-10-18 보상 통합 54개는 중복 사망·재진입·0/100%·수량 경계·합산·알림 대기열·실패 보존을 보고한다. 2026-10-20 재료 검증은 시드를 선택한 5종×0/1/2개 총 15경로, 중복 치명타 보상 1회, 인벤토리/런/결과 수량 일치와 Play 재진입 복원을 보고한다. 이는 확률 통계 검증이나 수동 전투 검증이 아니다. 결과 정산 검증은 저장 ID 일치·재열기·저장 실패 후 재시도의 중복 무지급을 보고한다.

**기획 대조 / 추가 확인:** 확정된 처치·드롭·클리어·실패 보상 원칙과 부합한다. 보유 스킬 중복 제외는 구현 세부이며 최종 중복 보상 정책 승인으로 확대하지 않는다. 다른 난이도/층의 지급 연결·최종 보상 표, 빌드 재실행·장시간 전투는 후속 확인 대상이다. 초기 기록의 인벤토리 정지 정책은 같은 날 비정지 수정으로 대체됐다.

## 15. 기획 상태 정리

### 15.1 확정된 규칙

- 몬스터 처치 시 돈과 경험치 즉시 획득
- 일반 몬스터 재료 드롭 확률 50%
- 드롭 성공 시 재료 1~2개
- 일반 몬스터 재료 직접 획득
- 던전 클리어 전용 아이템 보상 존재
- 스킬은 던전 클리어 보상으로 획득
- 별도의 던전 클리어 돈 보너스 없음
- 별도의 던전 클리어 경험치 보너스 없음
- 클리어 보상 최초 결과 진입 시 지급·저장
- 실패해도 이미 획득한 보상 100% 유지
- 결과창을 다시 열어도 보상 중복 지급 없음
- 이미 획득한 보상은 로비 복귀 이후에도 유지

### 15.2 폐기되었거나 적용하지 않는 규칙

- 일반 몬스터의 스킬 직접 드롭
- 보스 처치 후 상자 상호작용으로 보상 획득
- 던전 클리어 시 추가 돈·경험치 보너스 지급
- 실패 시 기존 획득 돈·경험치·재료 회수
- 결과창 버튼을 눌러야 보상을 지급하는 구조
- 결과창을 다시 열 때 보상 재지급

### 15.3 미확정 또는 확인 필요

- 몬스터별 정확한 돈 지급량
- 1층 쉬움 EXP 초기안의 실제 적용/검증 및 최종값, 다른 난도·2층 이후 경험치
- 재료 아이템 이름 및 ID
- 층·난이도별 클리어 보상 목록
- 보스 및 엘리트 보상 구조
- 스킬별 획득 확률
- 난이도별 개별 보상 확률
- 획득 알림의 상세 애니메이션
- 결과창 보상 아이템 정렬 방식
- 중도 던전 이탈의 상세 보상 처리
- 실제 저장 및 지급 중복 방지 구현

미확정 사항은 새로 결정하거나 기존 프로젝트 데이터를 확인하기 전까지 확정하지 않는다.

## 16. 시스템 검증 기준

향후 Codex 및 Unity에서 실제 검증할 항목이다. 현재 모든 항목의 검증이 완료되었다는 의미는 아니다.

### 몬스터 처치

- 돈과 경험치가 처치 시 즉시 지급되는가?
- 재료 드롭이 50% 확률 명세를 따르는가?
- 드롭 성공 시 수량이 1~2개인가?
- 하나의 사망으로 보상이 중복 지급되지 않는가?

### 던전 진행

- 방 이동 시 획득 보상이 유지되는가?
- 여러 방에서 획득한 보상이 런 기록에 누적되는가?

### 클리어

- 보스 처치 후 클리어 보상이 지급되는가?
- 최초 결과 진입 과정에서 보상이 저장되는가?
- 결과창을 다시 열어도 보상이 중복 지급되지 않는가?
- 돈과 경험치가 별도 보너스로 추가 지급되지 않는가?

### 실패

- 최종 사망 후에도 획득한 보상이 유지되는가?
- 미획득 클리어 보상이 지급되지 않는가?
- 로비 복귀 후 획득 보상이 유지되는가?

### 저장

- 게임을 다시 실행한 뒤 보상이 유지되는가?
- 이미 지급된 보상이 다시 지급되지 않는가?
