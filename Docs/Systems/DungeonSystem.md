## 1. 시스템 개요

### 1.1 목적

던전 시스템은 플레이어의 던전 입장부터 방 진행, 보스 처치, 클리어 및 실패, 재도전과 로비 복귀까지의 흐름을 관리한다.

각 전투 방에서 몬스터를 처치하여 다음 방으로 진행하고 마지막 보스를 처치하는 구조를 기본으로 한다.

### 1.2 주요 기능

- 던전 층 및 난이도 선택
- 던전 입장 조건 검사
- 던전 플레이 시작 및 초기화
- 일반 전투 방 진행
- 몬스터 전멸 시 출구 개방
- 다음 방 이동
- 런 내부 상태 유지
- 보스 처치에 따른 클리어 처리
- 최종 사망에 따른 실패 처리
- 던전 결과 및 재도전
- 로비 복귀

## 2. 던전 선택 및 입장

### 2.1 입장 위치

플레이어는 광산 입구가 존재하는 메인 씬에서 던전에 입장한다.

입장 흐름:

1. 플레이어가 광산 입구에 접근한다.
2. T 키를 입력하여 광산 입구와 상호작용한다.
3. 던전 선택창이 열린다.
4. 입장할 층과 난이도를 선택한다.
5. 입장 조건을 만족하면 던전을 시작한다.

기존 인벤토리에서 게임 시작 버튼을 누르던 임시 입장 방식은 최신 기획에서 대체되었다.

### 2.2 층 선택

던전 선택창에서 입장할 층을 선택할 수 있다.

선택한 층에 따라 다음 정보를 갱신한다.

- 층 이름
- 선택 가능한 난이도와 관련 정보
- 입장 필요 레벨
- 대표 이미지
- 클리어 보상 정보

전체 층 수 및 층별 정확한 설정값은 확인이 필요하다.

### 2.3 난이도 선택

각 던전의 선택 화면에는 4가지 난이도가 존재한다.

난이도를 변경하면 관련 정보를 갱신한다.

- 선택한 난이도 표시
- 입장 필요 레벨
- 던전 표시 정보
- 획득 가능한 클리어 보상

**확인 필요**

- 난이도별 명칭
- 난이도별 레벨 제한
- 몬스터 능력치 차이
- 몬스터 등장 구성 차이
- 보스 구성 및 능력치 차이
- 난이도별 보상 차이

이 항목은 기존 프로젝트 설정을 확인하기 전까지 새로운 수치를 확정하지 않는다.

### 2.4 던전 입장 조건

**확정 규칙**

던전의 입장 필요 레벨을 충족하면 입장할 수 있다.

이전 층 또는 이전 던전의 클리어 여부를 입장 조건으로 사용하지 않는다.

입장 조건:

`현재 플레이어 레벨 ≥ 선택한 던전의 입장 필요 레벨`

레벨을 충족하지 못하면 입장하지 못하며, 부족한 입장 레벨에 대한 안내 메시지를 표시한다.

입장 불가 버튼은 시각적으로 구분하되 안내 메시지를 표시할 수 있어야 한다.

## 3. 던전 플레이 흐름

### 3.1 기본 진행

1. 선택한 층과 난이도로 던전에 입장한다.
2. 일반 전투 방에 플레이어와 몬스터를 배치한다.
3. 플레이어가 몬스터와 전투한다.
4. 모든 대상 몬스터를 처치한다.
5. 방 출구가 개방된다.
6. 출구를 이용하여 다음 방으로 이동한다.
7. 일반 방 진행 후 보스 방으로 이동한다.
8. 보스 처치 시 던전을 클리어한다.
9. 던전 결과를 표시한다.

### 3.2 일반 전투 방

일반 방에는 해당 방의 전투 대상 몬스터가 배치된다.

방 진행 규칙:

- 전투 대상 몬스터가 남아 있는 동안 출구를 사용할 수 없다.
- 모든 대상 몬스터가 사망하면 출구가 열린다.
- 출구를 이용하여 다음 방으로 진행한다.
- 방 이동으로 인해 진행 중인 런의 주요 데이터가 초기화되어서는 안 된다.

### 3.3 일반 방 랜덤 후보

**2026-10-21 — 일반 방 후보 및 진행 구조 최신화 / 사용자 승인 완료.**

- 일반 전투 방은 신규 제작한 7종의 맵을 랜덤 후보로 사용한다.
- 기존 테스트용 일반 맵은 랜덤 후보에서 제외한다. 후보 제외는 원본 에셋 삭제를 뜻하지 않는다.
- 신규 맵 A는 맵 5로 편입하며 별도 중복 후보로 사용하지 않는다.
- 7종은 일반 방의 맵 종류 수이며 한 번의 던전에서 진행하는 방 수와 구분한다.
- 과거 일반 맵 9종의 설계는 보존하지만 현재 후보 수에 합산하지 않는다.

선택 가중치·중복 등장 허용 여부·구체적인 알고리즘과 층/난이도별 다른 후보 목록은 실제 구현 확인 대상으로 남긴다. 상세 맵 구조와 맵 4 수정·맵 5 편입은 [MapSystem.md](MapSystem.md)를 따른다.

몬스터 전멸 시 출구 개방, 출구를 통한 다음 방 진행, 현재 방 입구 부활, 방 이동 시 런 상태 유지, 일반 방 이후 보스 진행, 보스 처치 시 클리어와 결과 정산은 그대로 유지한다.

### 3.4 방 이동

방 출구를 이용하면 다음 방으로 진행한다.

방 이동 과정에서는 다음을 보장해야 한다.

- 플레이어를 다음 방의 입장 위치로 이동
- 해당 방의 몬스터 및 출구 상태 적용
- 이전 방에서 남은 공격 판정 정리
- 새로운 방의 카메라 제한 영역 적용
- 런 내부 플레이어 상태 유지

몬스터 생성 위치, 카메라 처리 및 상세 방 교체 방식은 맵 시스템과 연동한다.

## 4. 런(Run) 상태 관리

### 4.1 런의 범위

한 번의 런은 선택한 던전과 난이도에 입장하여 클리어 또는 실패 결과에 도달하는 던전 플레이 단위를 의미한다.

결과창을 닫거나 다시 여는 행위는 새로운 런의 시작이 아니다.

### 4.2 방 이동 시 유지할 정보

| 정보 | 방 이동 시 처리 |
|---|---|
| 현재 체력 | 유지 |
| 남은 물약 | 유지 |
| 남은 부활 횟수 | 유지 |
| 획득한 돈 | 유지 |
| 획득한 경험치 | 유지 |
| 획득한 아이템 및 재료 | 유지 |
| 전투 기록 | 누적 유지 |

방 이동만을 이유로 체력, 물약, 부활 횟수 또는 전투 기록을 초기화하지 않는다.

### 4.3 영구 데이터와 런 데이터

던전 시스템은 런 내부에서 관리하는 상태와 영구 보유 데이터를 구분한다.

**런 내부 데이터**

- 현재 진행 중인 던전 및 난이도
- 현재 방 진행 상태
- 현재 체력
- 남은 물약
- 남은 부활 횟수
- 해당 런의 전투 기록

**영구 유지 대상**

- 돈과 경험치
- 레벨 및 성장 정보
- 획득 재료·아이템
- 스킬 보유 및 장착 정보
- 곡괭이·장비 정보

던전 보상은 저장 시스템과 연동한다.

획득한 보상은 방 이동 또는 결과창 전환 과정에서 사라지지 않아야 한다.

## 5. 부활 및 던전 실패

### 5.1 부활 횟수

확정된 규칙은 다음과 같다.

- 최초 생명을 포함한 총 생명: 3개
- 부활 가능 횟수: 2회

| 사망 횟수 | 남은 생명 | 처리 |
|---|---:|---|
| 0회 | 3 | 정상 플레이 |
| 1회 | 2 | 부활 |
| 2회 | 1 | 부활 |
| 3회 | 0 | 던전 실패 |

기존의 부활 3회 규칙은 폐기되었다.

### 5.2 부활 위치

플레이어는 현재 진행 중인 방의 입구에서 부활한다.

처음 던전에 입장했던 방으로 돌아가지 않는다.

보스 위치를 강제로 변경하는 추가 규칙은 적용하지 않는다.

### 5.3 던전 실패

부활 2회를 모두 사용한 뒤 다시 사망하면 던전 실패로 처리한다.

실패 시 다음 규칙을 적용한다.

- 플레이어는 사망 상태를 유지한다.
- 결과창을 닫더라도 이동 가능 상태로 복구하지 않는다.
- 이미 획득한 보상은 유지한다.
- 아직 획득하지 않은 클리어 보상은 지급하지 않는다.

플레이어 부활 동작과 생명 HUD의 상세 사항은 `PlayerSystem.md`에서 관리한다.

## 6. 보스 방 및 던전 클리어

### 6.1 보스 방

일반 방을 진행한 뒤 보스 방에 도달한다.

현재 확인된 보스는 돌골렘이다.

돌골렘은 5종 공격 패턴을 기준으로 개발이 진행되었다.

정확한 보스 능력치 및 개별 공격 규칙은 `BossSystem.md`에서 관리한다.

### 6.2 클리어 조건

**보스를 처치하면 해당 던전을 클리어한다.**

보스 처치 후 기존의 보상 상자 상호작용을 요구하지 않는다.

최신 보상 처리 방향:

1. 보스 처치
2. 던전 클리어 처리
3. 클리어 보상 지급 및 저장
4. 던전 결과창 표시

보상 확정은 최초 결과 표시 시점에 수행하며 결과창의 열기·닫기 동작과 분리한다.

### 6.3 클리어 이후 상태

클리어 결과창이 표시되어도 플레이어는 이동할 수 있다.

결과창을 닫고 주변을 돌아볼 수 있다.

닫힌 결과창은 별도의 버튼을 통해 다시 열 수 있다.

결과창을 다시 열어도 보상이 중복 지급되거나 새 런이 시작되지 않는다.

이동 외 공격과 스킬 사용 가능 범위는 현재 구현 확인이 필요하다.

## 7. 던전 보상 연동

### 7.1 몬스터 처치 보상

몬스터를 처치하면 돈과 경험치를 즉시 획득한다.

일반 몬스터 재료 드롭은 다음 공통 명세를 따른다.

- 드롭 성공 확률: 50%
- 성공 시 수량: 1~2개

자세한 드롭 처리 및 개별 보상은 `RewardSystem.md`에서 관리한다.

### 7.2 클리어 보상

던전 클리어 시 클리어 전용 아이템 보상을 지급한다.

별도의 클리어 돈·경험치 보너스는 없다.

이미 획득한 몬스터 처치 보상을 결과창에서 다시 지급하지 않는다.

### 7.3 실패 보상

던전 실패 시 이미 획득한 보상을 100% 유지한다.

- 돈
- 경험치
- 재료
- 이미 획득한 아이템

아직 획득하지 않은 보스 및 클리어 전용 보상은 지급하지 않는다.

### 7.4 보상 지급과 저장

클리어 보상은 결과창 최초 진입 시점에 지급하고 저장한다.

다음 행동으로 인해 보상이 손실되거나 중복 지급되어서는 안 된다.

- 결과창 닫기
- 결과창 다시 열기
- 결과창에서 로비로 이동
- 퍼즈 메뉴에서 로비로 이동
- 게임 종료 및 재실행

정확한 저장 처리 방식은 `SaveSystem.md`에 따른다.

## 8. 던전 결과 처리

### 8.1 결과 유형

결과 유형은 클리어와 실패로 구분한다.

**클리어**

- 보스 처치 시 발생
- 클리어 전용 보상 지급 대상
- 플레이어 이동 가능

**실패**

- 부활 2회 소모 후 최종 사망 시 발생
- 이미 획득한 보상 유지
- 플레이어 이동 불가

### 8.2 결과창 기능

결과창은 획득 보상과 전투 기록을 표시한다.

주요 기록:

1. 클리어 시간 또는 진행 시간
2. 넣은 데미지
3. 받은 피해량
4. 회복량
5. 처치한 몬스터 수
6. 사용한 부활 횟수

전투 기록은 해당 런 전체를 기준으로 유지한다.

### 8.3 결과창 닫기 및 재열기

- 결과창을 닫을 수 있다.
- 닫힌 상태에서 우측 하단에 다시 열기 버튼을 표시한다.
- 다시 열면 동일한 런의 결과를 표시한다.
- 결과 확인으로 보상이 다시 지급되지 않는다.
- 결과창을 닫는 것만으로 새 런이 시작되지 않는다.

결과창의 레이아웃, 색상, 연출 및 상세 UI는 `UISystem.md`에서 관리한다.

### 8.4 전투 기록의 미확정 계산 규칙

다음 사항은 기존 구현 확인이 필요하다.

- 초과 피해를 총 피해량에 포함하는지
- 최대 체력을 초과하는 회복량을 제외하는지
- 부활 시 체력 복원을 회복량에 포함하는지
- 퍼즈 시간 및 로딩 시간을 진행 시간에서 제외하는지

## 9. 다시 시작 및 로비 복귀

### 9.1 다시 시작

결과창의 다시 시작 버튼을 선택하면 동일한 층과 난이도로 새로운 런을 시작한다.

**확정 초기화 규칙**

- 첫 번째 방부터 시작
- 플레이어 체력 초기화
- 물약 3개로 초기화
- 부활 가능 횟수 2회로 초기화

기존 영구 성장 및 획득 보상은 유지한다.

새 런에서 이전 결과창의 결과나 보상 지급 상태를 재사용하여 중복 지급이 발생해서는 안 된다.

### 9.2 로비로 이동

로비로 이동하면 현재 던전 진행을 종료하고 메인 로비로 돌아간다.

이미 획득하고 저장한 보상은 유지한다.

로비 복귀를 위해 결과창의 보상 지급 버튼이나 별도의 보상 상자 상호작용을 요구하지 않는다.

### 9.3 퍼즈 메뉴와 로비 이동

퍼즈 메뉴를 통해 로비로 이동하더라도 이미 획득한 보상은 사라지지 않아야 한다.

단, 클리어·실패가 확정되기 전 자발적으로 던전을 종료하는 행위의 상세 종료 규칙은 현재 자료만으로 확정할 수 없다.

해당 부분은 기존 구현 확인 및 별도 검토 대상으로 남긴다.

## 10. 다른 시스템과의 연동

| 연관 시스템 | 던전 시스템과의 관계 |
|---|---|
| MapSystem | 방 선택, 생성, 이동, 카메라 경계 |
| PlayerSystem | 체력, 부활, 사망, 물약 |
| MonsterSystem | 몬스터 등장 및 전멸 판정 |
| BossSystem | 보스 등장, 사망, 클리어 |
| CombatSystem | 전투 상태 및 남은 공격 판정 정리 |
| RewardSystem | 처치 보상, 클리어 보상, 실패 보상 |
| ProgressionSystem | 경험치 및 레벨 정보 |
| UISystem | 던전 선택창, 결과창, HUD |
| SaveSystem | 획득 보상 및 영구 성장 유지 |

### 10.1 맵 변경 시 유의사항

2026-10-21 승인된 맵 구조·후보 개편을 적용하더라도 다음 기존 기능을 유지한다.

- 방 전멸 판정
- 출구 개방
- 다음 방 진행
- 현재 방 입구 부활
- 플레이어 런 데이터 유지
- 보상 지급 및 저장

### 10.2 몬스터 확장 시 유의사항

돌 몬스터뿐 아니라 철, 수정, 석탄, 자철석 몬스터도 방 전멸 판정에 정상적으로 연결되어야 한다.

몬스터 종류에 따라 출구 개방 판정이 누락되지 않도록 한다.

### 10.3 결과 및 저장 연동 주의사항

결과창을 닫거나 로비로 이동할 때 보상이 사라지지 않아야 한다.

동일한 런의 결과를 다시 확인하는 것만으로 보상이 반복 지급되어서는 안 된다.
