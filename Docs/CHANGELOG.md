## 2026-10-21 — 일반 맵 7종 및 직사각형 캔버스 구조 확정

**변경 유형:** 맵 시스템 기획 확정 및 구현 완료 보고

### 확정된 기획 변경

- 모든 일반 맵에 직사각형 전체 캔버스 적용
- 이동 불가 영역의 암석·암벽 채움과 맵별 고유 이동 영역·동선 유지
- 직사각형 캔버스 경계 기준 카메라 제한, 내부 벽·암석과 경계 구분
- 신규 제작 일반 맵 7종을 랜덤 후보로 사용하고 기존 테스트 일반 맵은 후보에서 제외
- 신규 맵 A를 맵 5로 편입하고 번호 충돌·별도 8번째 중복 후보 방지
- 맵 4 좌측 상단 붕괴 암석 구역 및 몬스터 배치 수정
- 붕괴 암석의 파괴·신규 상호작용 기능은 추가하지 않음
- 기존 출구·방 이동·현재 방 입구 부활·런 상태/획득 보상 유지·보스 진행과 결과 정산 규칙 유지

과거 일반 맵 9종 설계는 MapSystem §4에 보존하고 현재 신규 7종과 합산하지 않는다. 과거 맵 5의 설계와 A에서 편입한 현재 맵 5는 구분한다. 후보 7종은 맵 종류 수이며 한 런의 진행 방 수가 아니다.

### 작업 제한과 확인

WORK_STATUS 및 참고 기획 파일은 수정하지 않았다. Unity 코드·씬·프리팹·사용자 저장 데이터는 수정하거나 초기화하지 않았고, 기존 Git 변경을 폐기하지 않았다. 컴파일·Unity MCP 플레이 테스트는 이번 문서 전용 작업에서 실행하지 않았다. 문서 대조에서 기존 원문의 삭제·변경은 승인 상태 표기와 이 문서의 등록 안내 보정 외에 없었으며, 추가된 문서 링크의 대상 파일 존재를 확인했다. 수정 문서는 14개이고 WORK_STATUS의 바이트 일치 및 기존 비문서 변경 파일 39개의 SHA256 일치를 확인했다.

수정하지 못한 대상 문서는 없다. WORK_STATUS는 보존 대상이므로 수정하지 않았다. 기존 DEVELOPMENT_STATUS.md 참조는 관리 구상으로 보존하고, 실제 Docs에 파일이 없는 점과 현재 WORK_STATUS 기준 운영을 GDD에 명시했다.

- 별도 클리어 돈·경험치 보너스 없음. 실패 시 이미 획득한 보상 100% 유지.
- 클리어 보상은 **결과 최초 진입 시 지급·저장**, 결과창 재열기 시 중복 지급 금지.
- 레벨업당 스탯 포인트 1개. 영구 성장·아이템·장비·스킬 데이터 보존.
- 곡괭이는 메인 씬에서 돈·재료를 사용해 제작하는 방향; 제작 비용과 구현 여부 미확인.
- 스킬은 던전 클리어 보상으로 획득·장착, 일반 몬스터 직접 스킬 드롭 아님.
- 인벤토리 및 던전 선택창은 시간을 정지시키지 않음. ESC 퍼즈와 구분.
- 기존 맵 9종의 설계 기록. 직사각형 캔버스·암석 채움, 맵4 개선, 맵 A는 **재검토 중**.
- 도트 느낌은 검토 중. 최종 픽셀/PPU/타일 규격 미확정.

### 명확히 적용하지 않을 과거 안

- 이전 층을 모두 클리어해야 다음 층 입장 가능하다는 종전 해금 조건.
- 부활 3회, 최종 사망 시 획득 재화 회수, 보스 상자 T 상호작용을 통한 클리어 보상 지급.
- 일반 몬스터의 직접 스킬 드롭, 인챈트를 주된 스킬 획득 경로로 복원.
- 무너진 벽을 자동으로 파괴 가능한 벽으로 변경, 모든 공격 범위 일괄 축소.
- 모든 공격에 화면 흔들림 강제 적용, 보스 부활 시 위치 강제 이동, 사망 즉시 HP바 숨김 강제 적용.
- 검토 중인 맵 구조와 미확정 능력치·제작 수치를 승인 완료로 간주하는 행위.
