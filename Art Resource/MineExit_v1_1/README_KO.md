# MineExit v1.1 — 횃불 꺼짐·점등·켜짐 보완

기존 MineExit_v1 출구를 유지하고 두 작은 등/횃불 받침 내부와 인접한 극히 작은 조명 반사만 수정했다. 열린 갱도·문틀·암벽·문짝·철판·못의 위치와 개방 경로는 그대로다. 기존 등받침을 긴 횃불이나 다른 소품으로 교체하지 않았다.

## 게임용 파일

| 파일(Sprites/) | 실제 크기 | 용도 |
|---|---|---|
| MineExit_Locked_128x64_v1_1.png |128×64|닫힌 문, 꺼진 횃불|
| MineExit_Open_128x64_v1_1.png |128×64|열린 문, 따뜻한 주황색 점등|
| MineExit_Opening_6f_128x64_v1_1.png |768×64|기존6프레임 개방+점등|
| MineExit_OpenTorchLoop_4f_128x64_v1_1.png |512×64|선택용, 개방 후 작은 불꽃 변화 루프|

전부 RGBA 투명 PNG, 셀128×64, PPU64, 중앙 Pivot 픽셀(64,32)/정규화(0.5,0.5), 표시 캔버스2×1유닛이다. 알파0/255와 기존 외부 투명도를 그대로 유지한다. 갱도 내부는 불투명한 암부로 유지된다. 이 리소스는 별도 Light2D나 새 게임 기능을 요구하지 않는다.

## 연출과 시간

- 잠김: 기존 받침/금속 테두리는 유지하고 내부는 어두운 색으로 바꿨다. 불씨·추가 주변 광채는 없다. 문 색은 바꾸지 않아 주변 바닥과 구분된다.
- 점등: F1 꺼짐 → F2 아주 작은 주황색 불씨 → F3 불씨 성장 → F4 밝기 증가 → F5 완만한 점등 → F6 안정된 켜짐. 부드러운 블러 대신 몇 픽셀의 단계적 주황색 빛과 작은 목재 반사를 사용한다. 흰색 섬광·큰 광채·문 전체 발광은 없다.
- 열림: 갱도 통행 영역을 가리지 않으며 양쪽 받침 안에만 작은 따뜻한 불꽃이 유지된다.

|---|---:|---:|---:|---:|
|F1|0px|0|60|0.00초|
|F2|좌우 각3px|0.15|70|0.06초|
|F3|각8px|0.33|80|0.13초|
|F4|각15px|0.55|100|0.21초|
|F5|각22px|0.78|110|0.31초|
|F6|각26px/완전 개방|1.0|100|0.42초|

클립은 기존 시험안과 같은 **총0.52초**다. F1은 v1.1 잠김 PNG, F6은 v1.1 열림 PNG와 같은 이미지다. 마지막 열린 상태는0.42초부터 표시된다. 시간/강도는 Unity 적용 전 제안값이며 게임의 최종 확정값이 아니다.

선택 루프는4프레임/총0.70초(180/160/200/160ms). Open PNG와 같은 프레임으로 시작하며 불꽃 끝1픽셀과 작은 색 변화만 반복한다. 받침·갱도·문은 고정이다. 루프를 쓰지 않으면 Open PNG를 그대로 유지해도 된다. 루프는 닫힌 문에서 재생하지 않는다.

**몬스터 전멸 즉시 기존 출구 개방 판정을 유지한다.** 애니메이션이나 횃불 루프의 종료를 기다려 출구 통과를 켜지 않는다. 현재처럼 이미 문에 닿은 플레이어가 즉시 다음 방으로 이동하면 시각 애니메이션이 끝까지 보이지 않을 수 있으며 이를 이유로 판정을 지연하지 않는다.

## Unity 적용 주의사항

이번 작업은 아트 제작만 수행했다. 코드·프리팹·Collider·Trigger·전투·방 전환 규칙을 변경하지 않았다.

1. PPU64 / Point / Compression None / Mip Maps Off / Alpha is Transparency On. 정지2개는Single, 개방/선택 루프는Multiple, Grid Cell128×64. Max Size1024 이상으로 자동 축소를 막는다.
2. 각 n번째 셀 Rect=(128×n,0,128,64), n은0부터. Pivot center. 기존v1과 같은 위치·시각 Transform을 사용한다.
3. **가로 Scale 2배 중복 주의:** v1 제작 당시 Map01~10의 RoomExit Root Scale(2,1,1), Collider 로컬Size(1,1)로 월드2×1을 구성했다. 새 이미지 자체도 PPU64에서2×1이므로 해당 루트 렌더러에 그대로 넣으면4×1로 늘어날 수 있다. Collider 유지를 위해 Root Scale을 바꾸지 않는다. 별도 시각 자식 Local Scale(0.5,1,1)을 사용하는 방법 등이 후보이며 실제 현재 배치 구조는 적용 Codex가 재확인한다. 이미v1이 올바르게 적용된 시각 구조라면 그 구조를 유지하고 PNG만 교체한다.
4. **적갈색·초록색 Tint 중복 주의:** 기존 RoomExit.cs의 lockedColor/openColor가 새 이미지에 곱해지면 목재와 불꽃이 붉거나 초록으로 변한다. 아트용 렌더러는 중립 흰색 tint를 사용하도록 통합 담당자가 확인해야 한다. 기존 IsOpen/Trigger/레이어/즉시 통과 처리는 그대로 유지한다. 이 패키지는 tint 코드를 수정하지 않았다.
5. 개방 이벤트에 시각6프레임을 한 번 재생한 뒤 Open 또는 선택 루프를 유지한다. 게임 판정은 이벤트 순간 즉시 개방하며 애니메이션0.52초를 새 상태/대기 조건으로 사용하지 않는다.
6. 조명은PNG에 포함된 작은 색 변화다. 별도 광원·광범위 반투명 번짐을 자동 추가하지 않는다. 플레이어/공격 효과보다 눈에 띄지 않는 수준을 우선한다.

## 검증 결과

- PNG4개의 실제 크기/RGBA/셀 분할/알파0·255 확인.
- v1과 비교해 조명 허용 영역 밖 RGBA 픽셀 정확히 동일. 문짝·문틀 형태·갱도 영역은 전 프레임 유지된다. 조명이 닿은 근처 목재의 색만 조금 변하며 형상은 바뀌지 않는다.
- 모든 프레임의 알파 전체 배열과 외곽 bbox가 대응하는v1 프레임과 동일하다. 캔버스 바깥 발광이나 잘림 없음.
- F1=잠김/F6=열림, 선택 루프F1=열림 PNG 일치. 기존 문짝 이동 및6프레임/0.52초 유지.
- 횃불 내부 평균 RGB 값은 F1~F6에서28.33→31.27→39.13→49.06→57.67→65.93으로 증가한다. 이는 픽셀의 단계적 밝기 확인이며 실제 화면의 지각적 자연스러움과 구분한다.
- 원배율/확대 정지 비교에서 꺼진 받침과 주황색 불씨가 구분되고, 열린 갱도와 통행 중심을 가리지 않는 것을 확인했다.
- GIF 전 프레임을 다시 디코딩하여 프레임 수·표시 시간·예상 화면을 검사했다.
- 기존v1/관련 Map 프리팹/RoomExit.cs의 작업 전후 해시 검사를 기록했다. 기존 파일을 덮어쓰거나 삭제하지 않았다.

미검증: 실시간 GIF 재생을 직접 관찰하지 못했다. 연속 점등의 자연스러움/불꽃 흔들림 인상은 최종 확인 완료로 보고하지 않는다. Unity Play·현재 카메라 크기에서의 가독성·실제 이벤트/표시 연결·tint 및배율 적용은 별도 Codex 확인 대상이다.
