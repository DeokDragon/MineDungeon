- `B_All_UI_Overview.png`: B 목재·금속 광산 장비형, 동일한 7종 UI.
- `Comparisons/AB_Entry/Clear/Failure/Pause/HUD/Slots/BossHP.png`: 각 UI 원규격 또는 확대 A/B 비교.

- `A/`, `B/`: 각 UI 독립 검토 PNG, 1920×1080 전투 HUD 배치 예상, 결과 다시 보기/E·R 중첩 검토.

**이번 폴더는 디자인 비교 전용이다. 최종 게임용 UI PNG 세트를 제작하거나 승인한 것이 아니다.** 시안 PNG의 글자·수치·표식·게이지는 비교를 위한 검토 합성이다. 이를 Unity 배경 Sprite로 잘라 Import하지 않는다. 최종 제작 시 장식/배경만 텍스트 없는 PNG로 분리하고, 기존 TMP·Image·Slider를 그대로 사용해야 한다. 신규 물약·스킬 아이콘은 제작하지 않았다.

## A/B 차이와 자체 검토

|항목|A — 암석·구리|B — 목재·금속|
|---|---|---|
|큰 메뉴|검푸른 석판·금속, 얇은 구리 띠와 작은 모서리 접합부|어두운 갈색 목재, 철제 띠와 작은 구리 리벳|
|기존 아트 연결|Tab 지도 중심의 통일성이 높음|타이틀 목재 버튼과 연결성이 높음|
|전투 HUD|재질 대비를 줄인 어두운 석판, 1~2px 테두리|목재 질감을 크게 줄인 금속·목재 바탕, 동일한 얇은 테두리|
|가독성|숫자와 붉은/청록 게이지가 선명함|따뜻한 분위기. 큰 패널의 나뭇결이 과하면 정보와 경쟁할 수 있음|
|추가 정리 후보|현재 코너의 작은 리벳을 Tab의 암석 조각형과 얼마나 통일할지 검토|큰 메뉴의 나뭇결 대비와 리벳 수를 더 줄일지 검토|

두 안 모두 큰 화면을 동일 장식으로 가득 채우지 않았다. 큰 메뉴에만 작은 모서리를 두고 하위 카드/통계 행/전투 HUD는 얇은 선으로 정리했다. HP 빨강, EXP 청록, 피해·회복 정보색은 두 안이 동일하다. 클리어/실패는 같은 프레임을 재사용하고 제목/부제 강조색과 기존 상태 설명만 다르게 했다.

자체 검토 기준으로 **A가 공통 기본형으로 더 차분하고 Tab 지도와 일관적**이다. B는 광산 장비의 재질감이 더 분명하다. 이 평가는 사용자 승인이나 최종 디자인 선택을 대신하지 않는다.

### 발견된 규격 불일치

퍼즈는 요청과 `CharacterSaveSetup`의 규격이620×600이지만 첫 MCP 실행 상태에서는 PauseCard가1440×810으로 조회됐다. **이번 시안은 요청한620×600을 사용하며, 실제 프로젝트 크기를 바꾼 것이 아니다.** 런타임 레이아웃/직렬화 값 불일치는 적용 담당자가 확인해야 한다. 던전 선택창의 읽기 상태 WindowBody는 기본 sizeDelta100×100으로 표시되어, 최종 레이아웃 실제 크기를 확인했다고 주장하지 않았다. 입장 시안은 요청1440×810과 코드의 상대 배치 구조를 기준으로 했다.

### 결과 다시 보기와 E/R

## 팔레트·픽셀 밀도·9-Slice

- A 제안색: 바탕#171F21, 음영#243033, 구리#8D683D, 밝은 구리#B58D58.
- B 제안색: 바탕#211E1A, 나무#39322A, 철#746F61, 구리#B58D58.
- 공통 글자#E3DDCF, HP#F00000, EXP/강조#43DCC6, 가한 피해#FFD166, 받은 피해#FF6B4A, 회복#4CD137. 실제 최종 TMP/게이지 색상을 코드에서 교체한 것이 아니다.
- 기존 아트의1~2px 외곽선·작은 픽셀군을 참고했다. 시안 확대에는 Point를 사용했다. 작은 글자가 축소된 전체 보드에서는 일부 획이 덜 보일 수 있어 독립 원규격 PNG로 확인한다.
- 큰 패널 시안은720×405의 내부 검토 스킨에서 모서리28px를 유지하는9분할 시험을 했다. 최종 Border 값 확정이 아니다. 큰 패널은24~28px 코너, 작은HUD는4~6px 접합부/1~2px 선을 별도로 제작하는 방향이다.
- 현재 시안은 재질과 장식 비교를 위한 불투명 바탕 검수다. **80% 배경 적용은 최종 UI 연결 시 별도 검증**한다. 최종 배경PNG 알파255×기존 Image 알파0.8 또는 PNG알파204×Image알파1 중 하나만 사용한다. 0.8×0.8=0.64로 중복 적용하지 않는다. 테두리·정보 요소까지 함께 어둡게 만드는 그룹 알파 사용도 주의한다.

## 제작 방식

내장 image_gen으로 A/B 빈 패널 재질 원형을 생성했다. 기준은 실제 Tab 프레임과 타이틀 목재 버튼이다. 주요 프롬프트는 A: '단일 어두운 석판 패널, 얇은 구리 테두리, 작은 코너, 저대비 질감, 텍스트/아이콘 없음', B: '단일 어두운 목재 패널, 철제 보강 띠, 작은 구리 리벳, 저대비 나뭇결, 텍스트/아이콘 없음'. 이후 동일한 확인 구조에 검토 텍스트·정보 레이어를 따로 합성했다. CLI/API 별도 이미지 생성은 사용하지 않았다.
