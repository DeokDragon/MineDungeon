## 이번에 바꾼 부분

|영역|혼합형 적용|
|---|---|
|큰 패널|A 암석·금속 배경과 구리 모서리 유지. 내부 질감58%+A 기본색42%로 균열 대비 완화. 프레임·코너는 그대로 유지|
|목재 적용 버튼|입장하기, 결과창 다시 시작/로비로 이동, 퍼즈의 계속하기/설정/광산 밖으로 귀환/게임 종료|
|목재 미적용|층·난이도 선택, 닫기, 정보 카드, 상태 HUD, Q/E/R, 보스 HP|
|버튼 결합 방식|B 내부의 저대비 목재 질감만 사용하고 A 구리선·선택색과 결합. 타이틀360×80 버튼 전체를 확대 복사하지 않음|
|결과창|기존 좌측 보상/우측 전투기록, 제목/설명, 기존6개 통계와 두 행동 버튼 유지. 클리어/실패 프레임 아트는 픽셀 단위 동일|

기존A와의 비교에서는 전체 패널이 목재로 바뀌는 것을 피했고, 행동 버튼만 재질이 구별되도록 했다. 큰 패널의 반복감은 새로운 타일을 추가하는 대신 기존 질감의 대비를 줄이는 방식으로 억제했다. HUD에는 이 큰 패널 질감 보정을 적용하지 않았다.

## 글자·숫자·게이지 분리

이번에는 검토 합성 이미지와 장식 원형을 명확히 분리했다.

- `Studies_ArtOnly/`: 글자·숫자·게이지·캐릭터/아이콘을 제외한 **검토용 프레임/버튼 아트 레이어**. 최종 납품 Sprite 세트가 아니다.
- `Preview_ContentOnly/`: 글자·숫자·게이지·기존 아이콘·표식의 별도 투명 검토 레이어. Unity용 텍스트 PNG가 아니다. 실제 적용 시 기존 TMP/Image/Slider가 이 역할을 담당한다.
- `Previews/`: 위 두 레이어를 합성한 검토 화면. 글자가 들어 있으므로 배경 Sprite로 Import하지 않는다.
- `Guides/`, `Comparisons/`: 설명/비교 이미지. 역시 게임용 아트가 아니다.

7종 모두 같은 캔버스의 ArtStudy/Content 분리 쌍을 제공한다. 버튼5상태도 빈 아트와 레이블을 따로 보관했다. 최종 제작에서는 기존 TMP를 PNG로 교체하거나 글자·게이지를 프레임에 구워 넣지 않는다.

결과 프리팹 기준 보상/기록 영역은 패널 내부(40,220,660,570)/(740,220,660,570)로 유지했다. 상태 정보·텍스트·게이지·버튼의 좌표를 디자인 편의를 위해 옮기지 않았다. 시안 수치는 이전 A/B와 동일한 검토 예시이며 실게임 결과를 새로 계산한 값이 아니다.

## 원배율 가독성 검토

- `Previews/Entry/Clear/Failure/Pause_1920x1080_ActualSize_Expected.png`: 실제 기준 화면 크기로 중앙 패널을 합성한 예상 화면.
- `CombatHUD_1920x1080_ActualSize_Expected.png`: 최신 승인 HUD 좌표에 상태·Q/E/R·보스HP를 표시한 배치 검토. 보스HP는 크기/위치 비교를 위해 표시한 것이며 캡처된 방에 보스가 실제로 등장했다는 뜻이 아니다.
- 결과창 예상 화면에서는 기존 BossHealthHUD의 결과창 표시 시 숨김 구조를 존중해 보스HP를 표시하지 않았다.
- 메뉴의 주요 문구와 결과값은 원배율 정적 합성에서 구별 가능했다. 전투 HUD는 얇은 A 프레임으로 내부 표시를 가리지 않는다. 슬롯은 단축키·수량/쿨타임을 프레임보다 위의 별도 내용 레이어에 둔다.
- 상태 HUD의 EXP12px 문구는 기존 A 기준을 유지한 가장 작은 정보다. 작은 모니터/실제 TMP 렌더링에서의 최종 가독성은 확인이 필요하다. 이번에 글자 크기·위치·기능을 변경해 해결하지 않았다.
- 물약은 이전 실제 HUD 캡처의 임시 표시를 재사용했다. 캡처에 섞인 Q 획 일부는 미리보기 추출 과정에서 인접 원본 픽셀로 정리했다. 원본 아이콘 파일이나 Unity 표시를 수정하거나 신규 물약/스킬 아이콘을 그리지 않았다.
- 축소된 전체 보드에서 작은 글자의 일부 획이 약해질 수 있다. 최종 판정은 별도 원규격/1920×1080 이미지로 한다.

정적 이미지 검토를 Unity Play/실제 상호작용 검증 통과로 보고하지 않는다.

## 색상·테두리·투명도

- A 기본색#171F21, 차가운 암석#243033, 구리#8D683D, 밝은 구리#B58D58.
- B 목재는#211E1A 계열의 어두운 내부 질감만 차용. 전투 HUD에는 목재 없음.
- 본문#E3DDCF. HP빨강#F00000, 기존 A의 HUD EXP#38D9C1와 결과/선택 청록#43DCC6 유지. 피해#FFD166, 받은 피해#FF6B4A, 회복#4CD137 유지.
- 작은 HUD/슬롯은1~2px 선, 큰 패널은 기존 코너를 보존한다.28px9-Slice는 이전 시안을 조합하는 시험값이며 최종 Border 확정이 아니다.
- `Background_Alpha_Once_Comparison.png`: 패널 배경만80%를 한 번 적용한 예상 비교. 테두리·목재 버튼·내용은 함께 흐리게 하지 않았다. 새 공통80% 정책을 모든UI에 강제한 것이 아니다.
- 기존 Tab의80% 배경은 그대로 유지한다. 최종 제작 시 PNG알파204+Image알파1 또는 PNG알파255+Image알파0.8 중 하나를 사용하고0.8×0.8 중복을 피한다.

## 기존 아트·기능 보존과 남은 확인

- 기존 Tab560×400 프레임·배경·아이콘과 타이틀 버튼은 수정하지 않았다. `Tab_Title_Hybrid_Continuity.png`에서 직접 비교할 수 있다.
- 결과 다시 보기/E·R의 겹침 이미지는 기존 A의 검토 이미지를 그대로 보존했다. 버튼/HUD를 숨기거나 옮기는 해결책을 적용하지 않았다. 실제 활성 조건·정렬 순서는 후속 확인 사항이다.
- 이전 조사에서 퍼즈 제작 코드620×600과 실행 상태1440×810 불일치가 있었다. 이번에는 요청620×600으로 시안을 만들었으며 실행 상태를 새로 조회하거나 프로젝트 크기를 수정하지 않았다. 적용 담당자가 확인해야 한다.
- 입장/퍼즈/실패는 구조 기반 예상 시안이고, 새 실제 상태를 실행해 촬영한 화면이 아니다. 기존 코드·프리팹 구조의 세부 근거는 상위 Concepts/README와 Specs/Unity_Layout_ReadOnly.json에 있다.
- 결과창의 ArtStudy와 내용이 분리돼 있으므로 기존 제목/보상/기록의 내부 등장 연출을 유지할 수 있는 후보 구조다. 실제 마스크/CanvasGroup/등장 시간 호환성까지 적용 검증한 것은 아니다.

## 실제 검증

- 요청한 원규격과 RGBA 파일을 확인했다. 개별 슬롯72×72, 7종의 아트/내용 캔버스가 동일한지 검사했다.
- 클리어/실패의 프레임 아트가 바이트 픽셀 단위로 동일하고, 버튼5상태가 서로 다른 픽셀임을 검사했다.
- 보스의 빨강HP와 지연 피해가 ArtStudy에 들어가지 않고 내용 레이어에 분리된 상태를 확인했다.
- 전체보드, 퍼즈/버튼5상태, 슬롯 원배율·확대, 결과창1920×1080 합성을 정적으로 검토했다.
- 이전 시안/기존아트/관련문서·씬·프리팹·코드100파일의 작업 전후 해시가 동일하다.
- 새 Unity 실행·Import·Play, 실제 TMP/마우스 입력·9-Slice·다해상도·전체 상태·결과 연출 회귀는 미실시다.
- Unity 코드·씬·프리팹·공식문서 수정, 원본 덮어쓰기, Git 커밋/푸시 없음.

최종 확정 및 실제 PNG 세트 제작은 사용자 검토 이후 단계다. 후속 아트 목록은 CSV에 있고, 이번 파일명/구성은 최종 게임용 Import 명세가 아니다.
