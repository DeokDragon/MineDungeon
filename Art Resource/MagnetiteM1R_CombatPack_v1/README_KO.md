## 기준 외형과 제작

원본은 D:/던전 게임/아트 리소스/몬스터 정지 이미지/M-1R.png 입니다. 기존 MagnetiteM1R_IdleMove_v1의 원본과 같습니다. 원본 및 기존 Idle/Move 폴더의 모든 파일 해시가 작업 전후 동일합니다.

imagegen 기본 내장 도구로 각 본체 5종과 VFX 4종의 편집/생성 초안을 만들었습니다. 본체 초안에는 얼굴/몸체 픽셀이 달라진 부분이 있어 그대로 축소해 사용하지 않았습니다. 최종 본체는 기존 원본의 부위 마스크를 재사용해 정수 픽셀 관절·광석 이동으로 재구성했습니다. VFX는 생성한 원화의 픽셀 클러스터를 정해진 셀/중심/반경/제한 팔레트로 정리하고 부드러운 배경광을 제거했습니다. ChargeHalo는 각도별 원화의 아크 분포를 고정 반경에 재배치했고 FieldImpact의 최외곽은 정확한 중심의 얇은 계단형 윤곽으로 보정했습니다. 생성 초안 자체는 게임 파일이 아닙니다. 사용 프롬프트는 Review/imagegen_prompts.json에 있습니다.

원래의 검푸른 몸체·작은 가슴 원형 구조·눈·균열·짧은 팔다리를 유지했습니다. 철 갑옷이나 거대한 수정 코어를 추가하지 않았습니다. 살아 있는 본체의 가슴 원형 구조와 발은 고정했습니다. 눈과 기존 푸른 균열의 RGB만 충전 정도에 따라 변경합니다. 몸체/발의 전체 이동이나 확대·축소는 하지 않았습니다. 팔은 상부 고정점을 기준으로 팔꿈치/손 쪽을 1~4px 모으거나 벌려 방출 자세를 만듭니다.

## 동작

- MagneticWindup: 기본 원본에서 시작해 광석을 안쪽1~2px 모으고 팔을 접습니다. 원래 눈/균열/연결선의 청록빛이 단계적으로 증가합니다. 발은 고정됩니다.
- MagneticImpact: 충전 마지막 자세에서 시작해 팔을 짧게 열며 F2에 가장 밝아집니다. F3에 광석이 안쪽에서 ±1px 흔들리고 F4에 감소합니다. 점프·이동·순간이동·본체 주변 피해 파동은 없습니다.
- Recovery: 팔/광석/빛이 기본으로 돌아갑니다. 마지막은 원본 및 기존 Idle F1과 전체 RGBA가 같습니다.
- Hit: 기본 자세 기반의 짧은 팔/광석/연결선 반응입니다. F3은 원본과 전체 RGBA가 같습니다. 기본 포즈 Hit를 공격 포즈에 그대로 덮으면 충전 밝기나 팔 모양이 바뀔 수 있습니다. 임의의 공격 중 Hit 전환까지 자연스럽다고 검증하지 않았습니다. 기존 공격 포즈 우선순위/피격 플래시·변위와의 실제 조합은 통합 시 확인해야 합니다.
- Death: 연결선 불안정→눈/균열 약화→광석 낙하→몸체의 원본 암괴 부위가 접혀 붕괴→잔재 감소→F7 완전 투명입니다. 몸체 전체를 축소해서 소멸시킨 방식이 아닙니다. 붕괴는 원본 부위의 정수 이동/최근접 회전과 겹침으로 구성한 2D 시범 표현입니다. 매끄러운 붕괴 인상은 실제 재생에서 추가 검토해야 합니다.

## 광석과 연결선

원본 광석 4개의 픽셀 수는 81/83/58/59입니다. 살아 있는 모든 포즈에서 형태/크기/개수를 그대로 보존합니다. 왼쪽은 +x, 오른쪽은 -x로 최대2px 이동하며 바깥쪽 이동은 없습니다. 세로 흔들림은 ±1px입니다. 광석을 옮긴 뒤 원본 픽셀/알파와 일치하는지 검사했습니다. 충전용 색 변경은 원래 몸체/눈/연결선 마스크에만 적용되므로 광석 표면도 원본 RGB를 유지합니다.

원본 선의 연결 대상과 경로를 유지한 채 양 끝의 변위를 보간했습니다. 원래 붙어 있던 선 픽셀이 벌어지는 구간에는 필요한 계단 픽셀만 보충했습니다. 원본의 성긴 반짝임 간격까지 전부 연속된 굵은 선으로 바꾸지는 않았습니다. 실시간 재생에서 선이 자연스럽게 반응하는지는 미검증입니다.

원본은 x=0과 x=63에 이미 닿아 있습니다. 따라서 모든 프레임의 좌우 테두리가 투명해야 한다는 검사는 적용하지 않았습니다. 각 원본 부위의 이동 후 좌표가 0..63 안에 들어가는지 확인하여 새 잘림을 방지했습니다. Death에서는 원래 4개 광석이 안쪽/아래쪽으로 떨어지고 최종 소멸합니다. 별도의 DeathFragments에 그 4개 전체 광석을 다시 넣지 않았습니다.

## 시간 — 검토용 배분이며 Unity에 강제하지 않음

- Windup: 120/130/150/160/170/170ms = 0.90초.
- Impact: 50/70/60/60ms = 0.24초.
- Recovery: 140/150/160/160/150ms = 0.76초.
- Impact+Recovery = 1.00초. 기존 후딜레이에 시간을 더하지 않는 미리보기 배분입니다. 실제 세부 배분은 Unity 통합 시 결정합니다.
- Hit0.15초, Death0.56초는 검토용입니다. 판정·사망·보상·전멸 처리를 기다리게 하는 이벤트는 없습니다.
- FieldImpact는 0.26초 중 마지막0.06초가 완전 공백입니다. 본체 Impact 종료보다20ms 늦게 끝나지만 해당 구간은 이미 공백이며 추가 후딜을 의미하지 않습니다.

## VFX 역할과 배치

ChargeHalo:96px/6f. 본체 중앙에 정렬하는 얇고 끊어진 푸른 충전 아크입니다. 중앙 내부는 비워 부유 광석의 선을 가리지 않게 했습니다. 본체 뒤에서 합성하는 검토 구성을 사용했습니다. 목표 위치에 생성하는 효과가 아닙니다.

FieldImpact:256px/6f. 저장된 목표 위치에서 짧은 중심 폭발→바깥으로 확산하는 원형 파동→빠른 소멸입니다. F6은 완전 공백이며 지속 장판이 아닙니다. 원래 자기장 공격 예고, 감속 링을 포함하지 않습니다. 원형 외곽은 정확한 중심을 기준으로 하고 내부 잔광/파편은 비대칭일 수 있습니다.

HitFragments:64px/4f. 작은 검푸른 파편과 소량의 푸른 잔광입니다. F4 공백. 기존 공통 피격 파편을 교체하는 자료이며 동시 적용을 전제로 하지 않습니다.

DeathFragments:128px/7f. 작은 보조 자철석 조각과 사라지는 에너지입니다. 본체 Death가 원래의 4개 광석을 담당합니다. 별도 VFX는 4개 전체 광석/큰 몸체를 복제하지 않고 작은 추가 조각만 담습니다. 그래도 동시에 재생할 때 파편이 많아지는지/어두운 바닥에서 충분히 보이는지는 실제 합성에서 미검증입니다.

## FieldImpact 월드 정렬 참고

셀256×256, Pivot(128,128), 가시 픽셀 중심 최대 반경 **111.99330337px**, 알파>0 합집합 bbox **[16, 16, 240, 240]** 입니다.

실제 피해 반경1.8유닛에 맞추는 시범 설정:

- PPU64 유지 → 균일 시각 Scale **1.02863293**.
- Scale1 유지 → PPU **62.21850187**.
- 식: radius_world = visible_radius_px × final_scale / PPU.
- 256px 전체 캔버스에는 투명 여백이 있으므로 캔버스 지름 자체를3.6유닛으로 맞추는 것과 다릅니다.
- 예고 반경2.0은 이 계산에 사용하지 않았습니다. Collider/공격 반경/저장된 목표 위치를 PNG 때문에 바꾸면 안 됩니다.
- 부모 배율·카메라·픽셀 모서리의 근사 오차는 실제 Unity 적용에서 확인해야 합니다.

다른 본체/VFX도 중앙 Pivot, Point/Compression None을 제안합니다. 본체는 PPU64 기준입니다. ChargeHalo는 본체와 같은 PPU64/Scale1 검토 합성이며 파편의 최종 월드 크기는 통합 시 결정합니다. 이번에는 .meta/Import/프리팹 설정을 쓰지 않았습니다.

## 검사 완료

- PNG9개 실제 크기/RGBA/프레임 수/셀 분할과 저장 후 픽셀 일치.
- 본체 살아 있는 프레임의 발·가슴 중심 유지, 광석4개 원본 형태·픽셀 유지, 원본 좌표 새 잘림 없음.
- VFX 바깥 네 변의 투명 여백, FieldImpact 중심/가시 반경 측정.
- Windup F1 = 기존 Idle F1, Windup F6 = Impact F1, Impact F4 = Recovery F1, Recovery F5 = 기존 Idle F1, Hit F3 = 기본 원본: 전체 RGBA 픽셀 일치.
- GIF 프레임 수·시간을 다시 디코딩해 검사. WebP의 프레임 수/알파/가시 RGBA가 PNG와 정확히 같은지 검사.
- 원본/기존 Idle·Move 폴더의 모든 파일 해시 불변.
- 정적 확대 비교 시트를 직접 검토했고 VFX 중심 어긋남과 부드러운 번짐을 보정했습니다.

## 미검증과 제한

실시간 GIF 재생 화면을 직접 관찰하지 못했습니다. 앞서 이 세션의 로컬 재생 화면 접근이 보안 정책으로 차단되었고 우회하지 않았습니다. 따라서 실제 시간에서의 연결선 자연스러움, 프레임 전환의 덜컹거림, Hit의 임의 공격 자세 복귀, Death 붕괴/파편 중복의 최종 인상은 **미검증**입니다. GIF 파일 생성/디코딩/정적 검토를 실시간 재생 확인으로 보고하지 않습니다.

기존 감속30%·1.5초/피해8, 예고/저장 목표 위치/공격 판정/화면 흔들림/기존 플래시를 변경하거나 새로 구현하지 않았습니다. 기존 공통 발동 펄스·피격/사망 파편과의 교체 연결도 수행하지 않았습니다. Unity 프로젝트/프리팹/코드/씬/공식 문서 및 다른 몬스터 리소스를 수정하지 않았습니다. Git 커밋·푸시를 하지 않았습니다. 출력은 Unity 프로젝트 밖의 이 별도 폴더뿐입니다.
