## 호환 규격

- PPU64, Sprite Single / Full Rect, Point, Compression None, Mipmap Off, 원본 크기 유지.
- RGBA, 실제 투명 배경. 불필요한 사각 벽/바닥 텍스처를 넣지 않았습니다.
- 유색 RGB는 **v1 A/B에서 추출한 31색의 부분집합**입니다. 투명 픽셀은 RGBA(0,0,0,0)입니다.
- Alpha는 24 단위의 단계값입니다. 접지/가루는 최대120~144, 코너/끝단의 벽 쪽 뿌리는 최대216, 넓은 면 결합 WallRoot는 최대96으로 억제했습니다. 물체 둘레를 부드럽게 흐리는 Blur는 최종 PNG에 없습니다.
- PNG에 PPU·Pivot·Sorting·SpriteMask 설정은 저장되지 않습니다. `.meta`는 제작하지 않았습니다.
- 현재 제안 표시 순서는 **기존 Default Layer의 -25**, 흰색 Tint, Scale1입니다. 기존 A(-35)와 벽(-30) 위, 기존 Rim(-20)/코너(-19) 아래입니다. Map01 전용본의 바닥 영역은 기존 A 유색 픽셀과 겹치지 않도록 잘라져 있습니다.
- 배우·공격 예고/VFX의 정렬이나 기존 A/B의 순서는 변경하지 않습니다.

### 전용본의 중복 방지 방법

- 기존 A65개의 실제 PNG·위치·회전 및 추가6개의 SpriteMask 범위를 복원해 유색 픽셀을 계산했습니다.
- 기존 B4개, 작은 돌 테두리 메시의 실제 UV/투명 픽셀도 계산했습니다.
- **기존 A의 바닥 유색 영역, B 유색 영역, 기존 작은 돌 테두리 영역은 신규 Fit에서만 Alpha0으로 제외했습니다.** 기존 파일·렌더러·마스크는 바꾸지 않았습니다.
- 인접 신규 Fit끼리도 한 픽셀을 두 번 덮지 않도록 영역 소유를 나눴습니다. 따라서 현재 배치에서 코너 음영이 중첩되어 진해지는 것을 피합니다.
- 넓은 WallRoot는 별도의 작은 돌 테두리가 생기지 않도록 짙은 외곽선 성분을 줄이고, 벽 안쪽의 면 색만 낮은 Alpha로 겹치도록 정리했습니다. 바닥으로 새 바위가 튀어나오는 소품이 아닙니다.

Fit에 보이는 투명한 틈은 기존 아트를 남겨 두기 위한 의도된 구멍입니다. **현재 배치 전용**이므로 A 위치·UV·마스크·지형이 바뀌면 다시 대조해야 합니다. 다른 맵이나 임의 좌표에서 그대로 재사용하면 구멍이 보일 수 있습니다.

## SpriteMask 배치 기준과 검사 범위

실제 Unity 적용 금지 조건에 따라 새 SpriteMask를 만들거나 기존6개를 수정하지 않았습니다. 미리보기는 Point 샘플·사각 범위 잘림을 재현한 **CPU 합성 검사**입니다. Unity SpriteMask의 실시간 렌더링을 시험했다고 보고하지 않습니다.

- 현재 Map01Fits는 이미 불필요 영역이 PNG Alpha0으로 제외되어 있어, 계획된 좌표에서는 추가 마스크 없이 검토할 수 있습니다. 기존 A의 마스크와 섞지 않습니다.
- 범용 직선의 짧은 시험은 48×128을 Scale1로 유지하고 0.75유닛 폭, 길이0.5/1/1.5유닛의 표시 범위로 자릅니다. 짧은 길이에 맞춰 Sprite를 압축하지 않습니다.
- 신규 -25 정렬 시험에 별도 마스크가 필요하면 CustomRange를 **-26~-25**처럼 신규물만 포함하도록 제안합니다. 현재 기존 A용 -36~-35 마스크는 유지합니다. 실제 범위 설정은 적용 담당자가 기존 B(-25)와 겹치지 않는 공간/정렬 범위를 확인해야 합니다. 같은 순서인 B까지 잘리는 마스크를 만들면 안 됩니다.
- 코너는 1×1유닛 캔버스와 결합점을 우선합니다. 0.75유닛 직선용 사각 마스크를 그대로 적용하면 L자의 한 팔이 잘립니다.
- EndCap은 끝 연결 영역, 직선은 가운데 영역으로 나눠 같은 픽셀을 중복 표시하지 않습니다. 독립 EndCap과 A 단면의 조합 예시는 `EndCap_ShortBody_JoinSimulation.png`입니다. **분리된 호환성 시험**이며, 기존 A65개의 실제 마스크를 바꾸라는 배치 지시가 아닙니다.
- 이 세트는 모든 절단 위치에서 RGB·실루엣이 자동으로 일치하는 오토타일/공통 소켓 세트가 아닙니다. 독립 EndCap은 직선의 절단 단면에 따라 추가 정렬이 필요합니다. 현재 조사된 Map01 접점에는 중복 제거된 J/R 전용본을 사용합니다.

`SpriteMask_ClipSimulation.png`는 세로·가로 짧은 직선의 범위 밖 Alpha0을 검증한 그림입니다. 마스크 잘림 검사와 실제 Game 연결 검증은 구분합니다.

## 긴 반복과 돌벽 결합의 남은 한계

`LongRun_Repeat_Example_2x.png`는 10유닛 시험 바탕에 기존 A를 유지하고 Var01/02를 **기존 A가 비어 있는 부분에만** 섞은 합성 예시입니다. WallRoot는 일부 위치에만 배치했습니다. 실제 Map01의 새 배치가 아니며, 두 변형을 원본 A 위에 그대로 겹치면 이 미리보기와 달라집니다. 새 변형은 기존 A와 똑같은 2유닛 간격으로 반복하지 않는 것을 권장합니다.

**기존 A65개를 삭제·수정하지 않는 조건이므로 원본의 밝은 퇴적물 리듬과 띠 인상을 완전히 지울 수는 없습니다.** 이번 결과는 코너의 빈 부분 및 벽 안쪽 연결을 보완한 검토안입니다. 전체 암벽 재작화, 원본 A의 반복무늬 제거, 모든 구간의 완전한 자연스러움 승인을 완료했다고 주장하지 않습니다.

원본 작은 돌 테두리도 그대로 남아 있으므로, 넓은 면 결합은 강도를 낮춰 기존 큰 암벽과 덜 분리되게 하는 보조 효과입니다. 비교 우측이 더 자연스러운지는 사용자 시안 검토 후 결정합니다.

## 검증 기록

`Specs/Validation.json`에 실행 결과를 보관했습니다.

- 게임용 PNG29개 모두 RGBA, 명세 크기, 바깥 테두리 투명, 유효한 유색 영역 확인.
- 모든 유색 RGB가 기존 A/B 팔레트31색에 포함되고, Alpha가24 단위인지 검사.
- 읽기 전용 스냅샷 A65/B4, Collider231개 확인. 현재 배치에 대한 신규 Fit의 작은 돌 테두리·기존 B 중복 픽셀0, 바닥 쪽 기존 A 중복 픽셀0.
