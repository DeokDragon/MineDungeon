# 돌골렘 P2 공격 애니메이션 v1

기존 P1 5종의 포즈·프레임 구성은 유지하고 현재 P2 Idle/Move 및 P2 원본의 벌어진 암석판·황금색/주황색 균열로 제작했다. 원본 픽셀을 관절 리그로 재배치했으며 P1 이미지를 단순 착색한 결과가 아니다. P1 원본·공격 PNG·P2 Idle/Move·Unity 코드·프리팹·씬·공식 문서는 수정하지 않았다. Unity 적용과 Play는 후속 작업이다.

## 프레임별 역할

- 도약 F1 기본, F2 힘 모음, F3 웅크림, F4 이륙, F5 다리 접기, F6 착지 준비, F7 접촉, F8 최대 압축, F9 흡수, F10 복원, F11 Idle. F12 낮은 대기, F13 팔을 모아 충격파 준비, F14 최대 긴장, F15 양팔을 벌려 힘 방출, F16 충격 흡수. 마지막 복귀는 F9→10→11을 재사용한다.
- 강타 F1 기본, F2 팔 올림, F3 팔 상승, F4 최대 준비, F5 내려치기, F6 접촉, F7 압축, F8 힘 풀기, F9 복원, F10 Idle. F11은 접촉 자세에서 다음 팔 올리기로 연결한다.
- 돌진 F1 기본, F2 어깨 준비, F3 낮은 방어, F4–7 유지 가능한 낮은 실행, F8 제동, F9 균형, F10 복원, F11 Idle. F5/F7에 반대쪽 발이 제한적으로 반응한다. 실제 월드 이동은 포함하지 않는다.
- 파편 F1 기본, F2 뒤로 당김, F3 준비, F4 발사 순간, F5 반동, F6 팔 안정, F7 복원, F8 Idle. F9는 재조준 시 팔을 다시 당기는 연결 포즈다.
- 낙석 F1 기본, F2 팔 올림, F3 준비, F4 소환, F5 힘 유지, F6 낙석 완료 대기, F7 팔 내림, F8 안정, F9 복원, F10 Idle. F11은 회차 사이 팔을 일부 낮춰 힘을 유지한다.

## P2 강화 공격 표시 순서

프레임 번호는1부터, 시간은ms다. 시간 배분은 **기존 전투 구간 안에서의 표시 제안**이며 피해·예고·물리·후딜을 바꾸지 않는다. 전체 구간을 일정 FPS로 재생하지 않는다.

### 강화 도약

1. 준비1.0초: F1(250)→F2(300)→F3(450).
2. 공중0.6초: F4(160)→F5(220)→F6(220). 실제 착지 확인이 늦으면 F6을 유지한다.
3. 착지 후1.3초: 실제 착지 이벤트부터 F7(80)→F8(120)→F9(200)→F12(900). 일반 Idle 복귀를 중간에 넣지 않는다.
4. 추가 예고0.8초: F13(300)→F14(500).
5. 충격파 실제 발동 이벤트에 F15 즉시 표시. 기존 최종 후딜0.7초 안에서 F15(80)→F16(120)→F9(170)→F10(160)→F11(170).

도약의 수평 이동과 JumpVisual 최대1.8유닛 상승은 기존 AI 담당이다. GIF는 본체 자세만 보여주며 세계 좌표의 도약 높이/이동을 중복해서 그리지 않았다. 충격파 원·VFX·피해는 포함하지 않는다.

### 강화 강타

- 첫 예고1.2초: F1(250)→F2(300)→F3(350)→F4(200)→F5(100).
- 첫 피해 이벤트에 F6. **동시에 시작되는 두 번째 예고1.2초 안에** F6(70)→F7(130)→F11(200)→F2(250)→F3(300)→F4(150)→F5(100). 접촉/압축을 보여주는200ms는 추가 후딜이 아니다.
- 두 번째 피해 이벤트에 F6. 후딜0.8초 안에 F6(70)→F7(130)→F8(190)→F9(210)→F10(200).

### 강화 돌진

- 준비1.0초: F1(250)→F2(350)→F3(400).
- Charge 진입 후 F4→5→6→7 각100ms 반복 또는 유지. 실제 돌진은 최대약0.9초이며 루프를 끝까지 기다리지 않는다.
- FinishCharge 발생 즉시 F8→9→10→11. 정상0.7초 배분은90/160/200/250ms. 벽 충돌1.2초 예시는150/280/340/430ms. 정확한 통합에서는 정규화한 구간 진행률을 사용해 기존 회복 종료 시각을 우선한다.
- 조기 종료·벽 회복 GIF를 별도로 포함했다. 벽은 본체에 그리지 않았다.

### 강화 파편

- 첫 예고0.9초: F1(250)→F2(300)→F3(350).
- 첫 FireShards 이벤트에 F4. **그 즉시 시작되는 두 번째 예고0.9초 안에** F4(70)→F5(90)→F9(340)→F3(400). 새 대기/Idle을 추가하지 않는다.
- 두 번째 FireShards 이벤트에 F4. 기존 후딜0.6초 안에 F4(70)→F5(90)→F6(150)→F7(140)→F8(150).
- 남은 투사체가 있으면 F8 유지. 투사체 정리가 늦다는 이유로 발사 포즈를 반복하지 않는다. 실제 재조준 방향/투사체 생성은 기존 코드가 처리한다.

### 낙석1~3회

- 첫 예고0.9초: F1(250)→F2(300)→F3(350).
- 각 낙하0.55초: F4(150)→F5(200)→F6(200). 실제 마지막 낙석 정리가 늦으면 F6 유지.
- 다음 회차가 있으면 회차 사이0.3초에 F11 유지. 다음 예고0.9초는 F2(300)→F3(600), 이어 F4→5→6. 회차 사이 Idle 없음.
- 최종 회차 정리 뒤에만 후딜0.7초: F7(160)→F8(180)→F9(180)→F10(180).
- Enhanced GIF는3회 예시, Basic GIF는1회 예시다. 2회는 같은 회차 블록을2번 사용한다. 회차 수/낙석 생성·위치·피해는 AI가 결정한다.

## 기본형 및 연계 A/B 재사용

별도 연계 스프라이트는 만들지 않았다. 위 시트의 기본 구간만 선택한다.

- 기본 도약은 F1–11만 사용, 충격파F12–16은 건너뛴다. 기본 강타는 F1–10, 기본 파편은 F1–8을 사용해 추가타를 만들지 않는다. Basic GIF/JSON에 P1과 같은 기본 시간 배분을 기록했다.
- 연계 A: 도약 F1–6 → 실제 착지부터0.2초 동안 도약F7(80)/F8(120) → 강타 예고1.2초 동안 강타F11(200)/F2(300)/F3(350)/F4(250)/F5(100) → 피해 이벤트 강타F6 → 강타 기본 후딜0.8초. 도약 일반 후딜0.7초나 추가 충격파를 삽입하지 않는다.
- 연계 B: 기본 돌진 실행 종료 → 후속 파편 준비0.2초 동안 파편F9(60)/F3(140) → 실제 FireShards 때 파편F4 → 기본 파편 후딜0.6초. 별도0.2초 대기와0.9초 예고를 다시 더하지 않는다. 벽 충돌이면 기존 코드처럼 파편 연결을 취소하고 돌진 벽 회복만 표시한다.
- 공격 중단·피격·사망·플레이어 사망·페이즈 연출은 기존 AI 상태가 우선이다. 이번 아트는 공격 취소 기능이나 추가 피해를 정의하지 않는다.

## Unity 적용 명세

- 160×160 셀 가로1줄, Sprite Multiple, Grid by Cell Size. n번째 Rect=(160×n,0,160,160), n은0부터. Pivot normalized(0.5,0.5), pixel(80,80).
- PPU128, 기존 Body Scale1.8 유지. Point / Compression None / Mip Maps Off / Alpha is Transparency On.
- 도약 시트 폭2560이므로 **Max Size4096 이상**으로 가져온다. 2048이면 자동 축소될 수 있다. 나머지도4096으로 통일해도 된다.
- 좌표는 이미지 좌상단 원점, +x오른쪽/+y아래. Unity 로컬=( (x−80)/128, (80−y)/128 ), 그 뒤 기존 Body Scale을 한 번 적용한다.
- 이벤트 우선: 실제 착지 ResolveAttack→도약F7, 두 번째 강타 피해→강타F6, 추가 충격파 피해→도약F15, 각 FireShards→파편F4, FinishCharge→돌진F8, Rockfall 최종 정리→복귀/다음 회차.
- 상태 전환이 발생하면 예시 GIF의 남은 시간을 기다리지 않는다. 도약F6/낙석F6/돌진루프/투사체 대기F8을 유지할 수 있다.
- 기존 flipX·Body 정렬을 유지하며 새 Root Motion이나 방향별 시트는 없다. 이번 작업에서 Unity 코드/프리팹/씬에 연결하지 않았다.
- 기계 판독용 `Unity_FrameTiming_Spec.json`에 각 프레임 순서·시간·이벤트·연계 경로를 기록했다. 각 쌍은 [프레임번호,ms]다.

- Previews: 공격별 Enhanced Native160/3x GIF, Basic Native160 GIF, Idle 전환 GIF, 기존 Move→Idle→공격 전환 GIF, 연계A/B Native160/3x GIF, 돌진 조기 종료·벽 회복 GIF.

- Review: P1·P2 같은 포즈 비교 원배율/3배, P2 5종 원배율 비교, 공격별 프레임 원배율/6배, validation.json.

실제 파일로 확인한 항목:

1. PNG5개의 실제 크기·58셀·RGBA·알파0/255·외부 투명도.
2. 각 포즈의 변환 전 픽셀 좌표 및 최종 경계 검사. 외곽 안전 여백은 최소7px, 잘림 없음.
3. 원본 P2 팔레트만 사용, 얼굴/눈 소스 픽셀 형태 보존. P1 원본을 표시하지 않음. 발광은 기존 균열 픽셀을 따라 함께 움직이며 새 광선/균열/VFX를 추가하지 않음.
4. 모든 신규 포즈가 하나로 연결된 실루엣. 시작/기본 복귀 Idle 픽셀 일치.
5. 원배율 정지 비교에서 팔 상승/착지 압축/낮은 돌진/파편 반동/낙석 유지 및 충격파 모음→벌림 포즈 구분 확인.
6. GIF 전 프레임 디코딩 후 프레임 수·지속 시간·예상 화면 일치 검사. GIF의256색 양자화는 게임 PNG에 적용하지 않음.
7. 작업 전후 보호 대상 파일 해시 검사. 변경 내역은 validation.json 참조.

미검증:

- 실시간 GIF 재생을 직접 관찰하지 못했으므로 연속 동작의 자연스러움·관성·무게감을 최종 확인 완료로 보고하지 않는다. 정적 원배율/확대 검토와 GIF 디코딩은 완료했다.
- 실제 Unity Play와 현재 카메라 게임 크기, AI 이벤트 동기화, 이동/JumpVisual 합성, 조기 취소, flipX, P2 연계의 실제 실행은 별도 Codex 검증 대상이다.
- 극단 자세에서 암석판의 겹침과 팔꿈치 암부가 실제 재생에서 자연스러운지 추가 검토가 필요하다. 동작을 명확하게 보이도록 원본 관절을 움직였으며 원본 캐릭터를 다시 디자인하지 않았다.
