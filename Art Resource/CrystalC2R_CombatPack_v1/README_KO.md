## 고정 코어와 동작

원본 코어 가시 픽셀 경계 중심은 PNG 좌표 (33.5,29.0)입니다. Cast/Fire/Recovery/Hit 모두 이 위치와 기본 외곽을 고정했습니다. 머리·눈·보라색 코어 둘레의 보호 영역을 원본과 비교했습니다. 사망의 파괴 이후에는 의도적으로 코어가 갈라지고 붕괴합니다.

- CastWindup: 기본 자세부터 시작합니다. 내부 코어 밝기를 6단계로 높이고 팔꿈치를 최대 약 30도 접어 에너지를 모읍니다. 무릎과 코어 아래 골반이 1px 버티는 자세로 바뀝니다. 코어/얼굴/어깨 결정의 크기·위치를 흔들지 않으며 어깨는 형태를 유지한 채 색 하이라이트만 반응합니다. 발은 고정합니다.
- Fire: F1은 Cast 마지막과 같습니다. F2에서 가장 강한 코어 색 변화와 짧은 팔 반동을 보이고 F3에서 밝기가 줄어듭니다. 본체에 긴 광선이나 물리 투사체를 그리지 않았습니다.
- Recovery: F1은 Fire F3과 같습니다. F2에서 발사 자세를 짧게 유지하고 팔/골반이 복귀합니다. 밝기가 단계적으로 줄며 F5는 설치된 Idle 첫 프레임과 완전히 같습니다.
- Hit: 어깨 1px/작은 팔 반응만 포함합니다. 코어는 원래 밝기·형태를 유지하며 파괴되지 않습니다. 플래시/전신 압축/추가 경직/공격 취소를 넣지 않았습니다. 공격 중 포즈가 우선인 경우 별도 Hit 시트를 굳이 덮어씌우지 않아도 되도록 독립 자료로 제작했습니다.
- Death: 코어 밝기 불안정→연결부 균열→큰 어깨 결정 일부 분리→코어 균열과 몸체 붕괴→결정 낙하→빛이 사라진 잔해→완전 투명으로 마무리합니다. 크고 화려한 폭발/번개는 넣지 않았습니다. 원본 결정과 암체의 색/텍스처를 재사용했고 보상/사망 처리 시점과는 무관합니다.

코어 충전은 Idle의 최대 약 2.1% 밝기 맥동보다 강합니다. 준비 동작은 원본 색을 흰색 방향으로 0→14→27→40→58→62% 혼합하고, Fire의 순간 최대는 80% 혼합입니다. 이는 기존 밝은 픽셀을 중심으로 한 내부 색 변화이며 새 발광 면적을 추가한 값이 아닙니다. facet 명암은 남기고 외부 에너지는 별도 VFX로 분리했습니다. 실제 밝기 수치는 Review/validation.json에 있습니다.

## 시간과 연결

- Cast: 100/110/120/130/140/150ms = 750ms.
- Fire: 40/70/70ms = 180ms.
- Recovery: 140/130/110/90/50ms = 520ms.
- Fire+Recovery 합계는 700ms입니다. 두 시각 클립 때문에 기존 후딜레이에 시간을 더하지 않습니다.
- Hit는 150ms, Death는 450ms 검토용 제안입니다. PNG는 시간을 강제하지 않으며 실제 상태의 시간/우선순위는 기존 게임 코드가 소유합니다.

전체 RGBA 픽셀 일치 확인:
1. Idle F1 = Cast F1.
2. Cast F6 = Fire F1.
3. Fire F3 = Recovery F1.
4. Recovery F5 = Idle F1.

코어 좌표와 두 발 접지는 모든 사망 전 전투 포즈에서 고정됩니다. Hit의 실제 공격 중 합성은 테스트하지 않았으며, Hit 리소스에 공격 포즈를 취소하는 지시는 없습니다.

## VFX 용도와 부착점

- CoreCharge: 48×48 셀 / 6f / 0.75초. 본체 없이 작은 청록 조각이 가슴 주변에서 모입니다. 실제 발사 때 종료하는 단발 시각 자료입니다. 마지막 프레임은 완전 충전 상태이며 투명 종료 프레임을 강제하지 않았습니다.
- FireFlash: 48×48 셀 / 4f / 0.18초. 짧은 다이아몬드형 방출과 작은 반짝임이며 긴 방향성 광선은 없습니다. 마지막은 투명입니다.
- ProjectileVisual: 32×32 셀 / 4f / 0.28초 반복 제안. 꼬리 없는 응축 수정탄입니다. 32px 캔버스의 투명 여백을 제외한 가시 픽셀 중심 반경은 약 11.068px이며 PPU64·배율1에서 가시 지름 약 0.346유닛입니다. 기존 판정 지름 0.35유닛을 참고한 래스터 근사입니다. 픽셀 모서리/부모 배율/실제 카메라에서의 시각 정렬은 추가 검토해야 합니다. 판정 반경을 이 이미지로 바꾸면 안 됩니다.
- CrystalImpact: 32×32 셀 / 5f / 0.20초. 작은 수정 파편이 짧게 튀고 사라집니다. 일반 피격 파편으로도 재사용할 수 있는 작은 독립 효과이므로 별도 HitFragments 파일을 만들지 않았습니다. 실제 타격 위치·피격 플래시와 겹쳤을 때의 밀도는 나중에 확인해야 합니다.
- CrystalDeathBurst: 96×96 셀 / 7f / 0.45초. 작은 결정 조각과 제한적인 청록 잔광입니다. Death 본체의 큰 어깨/코어를 통째로 중복하지 않습니다. 최종 프레임은 투명입니다.

CoreCharge/FireFlash의 프레임 중앙을 가슴 코어에 맞추려면, 중심 Pivot/PPU64의 본체를 기준으로 시각 부착 오프셋 x=+0.0234375, y=+0.046875 world units를 참고할 수 있습니다. 이는 PNG 위쪽 좌표를 Unity y위쪽으로 바꾼 시범 값입니다. 본체가 뒤집히거나 부모가 스케일되면 시각 부착점을 함께 확인해야 합니다.

이 오프셋은 코어 주변 시각 효과에만 해당합니다. ProjectileVisual은 가슴으로 이동시키지 말고 기존 물리 투사체 위치를 따라야 합니다. 실제 발사 원점/방향/피해/충돌은 기존 CrystalMonsterAI가 저장한 Rigidbody2D 위치/방향과 기존 투사체 루프가 처리합니다.

## 기존 구현과 적용 전 검토

CrystalMonsterAI.cs를 읽기 전용으로 확인했습니다. 현재 Projectile(origin,direction)은 저장된 위치에서 시작하고 Display의 공통 원형을 이동시킵니다. 신규 수정탄 PNG는 이 표시를 대체할 수 있는 자료이며 자동 연결되지 않습니다. 가슴 코어는 시각적 발사 암시일 뿐 물리 원점을 수정하는 근거가 아닙니다.

기존 예고선과 실제 투사체 루프를 수정하지 않았습니다. 기존 Impact의 범용 효과에 새 CrystalImpact를 무조건 추가하면 이중 파편/확산이 될 수 있으므로 나중에 표시를 선택해야 합니다. 본체 Hit/피격 플래시/압축과 새 작은 파편의 합성도 별도 통합 검토가 필요합니다.

## 검증한 항목

- PNG 10개 실제 크기/RGBA/투명 픽셀/정확한 셀 분할/저장 픽셀 일치 확인.
- 모든 셀 바깥 네 변이 투명하여 잘림이 없는지 확인.
- 사망 전 코어 외곽/위치, 머리/눈, 어깨 클러스터의 원본 형태, 발 접지 및 충전 색 변화 확인.
- Cast 밝기 순차 증가, Fire 순간 최고점, Recovery 밝기 순차 감소 확인.
- Idle→Cast→Fire→Recovery→Idle 연결의 지정 프레임 전체 픽셀 일치 확인.
- 모든 GIF를 다시 디코딩해 프레임 수/시간을 검사했고, 불투명 본체 GIF 프레임의 픽셀은 PNG 확대와 일치합니다.
- 무손실 WebP의 보이는 색과 알파는 PNG 확대 프레임과 정확히 일치합니다.
- 사망 본체/Burst의 중심 합성 및 프레임 시간 일치를 정적 프레임으로 검토했습니다.
- 원본/기존 Idle·Move/돌·철 리소스/참조한 프로젝트 코드의 해시가 변하지 않았습니다. ZIP 무결성 검사도 수행했습니다.

## 미검증과 품질 한계

이 채팅에서 로컬 file:// 브라우저 재생이 보안 정책으로 차단된 상태여서 실제 시간 흐름의 GIF 시각 재생을 직접 관찰하지 못했습니다. 우회하지 않았습니다. GIF 생성·디코딩 성공을 실시간 동작감 확인으로 보고하지 않습니다.

Unity Import/게임 내 프레임 타이밍/공격 중 Hit 우선순위/공통 충돌 효과와의 합성/실제 투사체 위치와 카메라에서의 범위는 미검증입니다. 실시간 연결의 자연스러움과 Death 결정 분해의 자연스러움도 추가 시각 검토가 필요합니다.

원본 정지 그림을 2D로 나누어 팔꿈치/무릎을 움직이고 사망 조각을 회전·이동한 시범 리소스입니다. 관절의 숨은 면과 결정 파단면을 새로 정밀하게 그린 최종 수작업 아트는 아닙니다. 이 부분은 남은 시각적 한계입니다.

파일 생성 실패는 없습니다. 정적 규격·코어 위치·잘림 검사를 통과했지만 실시간 연출까지 모두 검증 완료했다는 의미는 아닙니다. 상세 수치/파일 해시/검증 범위는 Review/validation.json에 기록했습니다.

## 변경
HeatExplosion: 96px 셀 단순 확대 대신 288px 좌표계에 원형 파동을 재구성했습니다. imagegen 편집 초안의 밝은 가장자리 분포를 참고하고, 원본 반경 진행·주황/붉은색 팔레트·동일 중심·프레임 알파·시간을 고정했습니다. 바깥 1~2px 하이라이트, 약 6~8px 주 파동, 끊어진 안쪽 붉은 잔열입니다. 원본 3~4px 두께를 3배 복제하지 않았습니다. 블러/공간 안티앨리어싱 없이 픽셀 중심으로 래스터화했습니다. 가장자리의 미세 패턴은 새로 정리되어 v1과 픽셀 단위로 같지 않습니다.

CoalEmbers: 원본 가시 픽셀/알파/파편 형태/궤적을 그대로 보존하고 일부 석탄 조각 가장자리의 1~3px만 원본 파동의 붉은색/주황색으로 바꿨습니다. 대부분 검은 석탄과 회색 면을 유지합니다. 발광 번짐·새 파편·불꽃·연기는 없습니다. imagegen 색상 편집 초안은 정확한 위치를 보장하지 못하므로 원본 마스크로 형태를 고정한 최종 파일을 제공하며, 초안 자체는 게임 파일에 포함하지 않았습니다.

## Unity 재적용 설정 제안 — 자동 적용하지 않음
